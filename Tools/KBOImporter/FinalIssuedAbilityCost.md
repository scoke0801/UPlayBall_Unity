# 최종 발급 능력치와 Cost 평가 연결

> 이 문서는 v19의 이력이다. 관측 가격까지 능력치 하한으로 올리는 규칙은 v20에서 폐기했다.
> 재평가 후 2000년 김동주의 일반 10코스트와 해당 시즌 레전드, 미달 EX 19장 취소 등 현재 규약은
> [관측 코스트 복원 기록](../../docs/reports/observed-cost-restoration-20260911.md)을 따른다.

## 원인

일반 Cost는 기록 학습 모델·관측 카드의 가격으로 먼저 결정되지만, 이후
`hitterRecordCalibration`과 관측 능력치 적용이 끝난 최종 발급 전력을 가격에서 다시 보지 않았다.
특수 카드 Peak 선정은 최종 전력을 사용하므로 동일 선수의 가장 강한 카드가 Cost 7인데
더 약한 다른 시즌은 Cost 10인 상태가 발생했다. 김동주 2003년은 역할 전력 81.2·Cost 7이었다.

이전 대응의 레전드 자격 미달 자동 제외는 철회했다. 명시적 레전드 선정·Peak Cost Gate를 유지하고
일반 카드 가격 평가에서 원인을 수정했다. 선수 이름이나 특수 카드 선정 여부는 산식 입력이 아니다.

## 평가 계약

Cost v19 / Balance v27, `elite-season-cost-v2`:

`최종 Cost = max(기록 모델 또는 관측 가격, 최종 발급 전력 하한, 연도 최고 성과 하한, 불펜 역할 하한)`

최종 전력은 `costDerivationTrace.roleWeights`와 현재 `baseAttributes`의 가중평균이다.
보정 전 Trace의 rating·composite를 재사용하지 않는다. 신뢰도 0.45·역할 출장량 비율 0.25 미만과
원기록 없는 연구 보충은 새 하한에서 제외한다. 기존 Source 평가·관측값은 추적 근거로 유지한다.

| 최종 전력 하한 | Cost 7 | Cost 8 | Cost 9 | Cost 10 |
|---|---:|---:|---:|---:|
| 타자 | 69 | 72 | 75 | 79 |
| 투수 | 74 | 76 | 79 | 81 |

기준은 수정 전 1982~2025 전체 Source 카드에서 Cost 7~10의 최종 역할 전력 중앙값이다.
타자는 68.98·71.88·74.26·78.81, 투수는 73.03·75.42·78.18·80.70으로,
이를 정수로 보수적으로 올림한 초기 경제 밸런스다. `elite_cost_policy.json`에서 조정한다.
가격을 능력치 한 가지로 전면 교체한 것은 아니므로 출장량·성과 가격에 따른 차이는 남는다.

## 변경 범위와 발급

Runtime 일반 카드 18,326장 중 531장(2.90%)의 Cost만 인상했다. 선수 신원·능력치·상한·구종·
포지션·원기록·카드 식별자·연도별 로스터를 포함한 가격 외 Runtime 콘텐츠는 모두 동일하다.
검사는 `audit_issued_ability_cost.py`가 전체 행과 연도 내용을 대조한다.

레어는 가격 자격에 따라 재료·발급 대상이 재선정된다. 레전드의 필수 재료 160그룹도 모두 유효하다.

## 대량 경기 검증

같은 Release 진단 빌드·Seed로 1982·1988·2000·2014·2025 각 4시즌을 비교했다.
전후 각각 정규시즌 11,520경기, 포스트시즌 등 포함 11,719경기, 연도별 결정론 5건이다.

20개 시즌의 팀 기록·세부 지표·순위·선수 기록·선발 순환 배열 모두 동일하다.
경기 입력까지 직렬화하는 checksum은 전후 다르므로 전체 직렬화 바이트 동일을 주장하지 않는다.
각 후보 내부에서 동일 Seed 재실행 checksum 5건은 각각 통과했다.

## 실행 검증과 반영

- 전체 Python 회귀 207개 통과. 전체 44년 재굽기와 Editor/Runtime 재로드·Hash 검증 통과.
- 실제 Production Runtime 로더 Fast/Full에서 619장·168레시피 전체 참조 통과.
- Headless EditMode: 카드 경제 Resolver 20개·역사 콘텐츠 정의 11개, 총 31개 통과.
- 역사 진단 Release 컴파일 오류 0. 기존 저장 직렬화의 SYSLIB0050 경고 3개가 남는다.
- `.tmp/final-ability-cost-v19/`에 전후 Archive·분포·경기 결과를 보존한다.
- 검증 후 기존 파일을 `PublicationBackup/`에 백업하고 로컬 Editor·Runtime·카탈로그 141파일을 동기화했다.
- Unity 내부 파이프라인 버튼·Play Mode와 3단계 World History 재굽기는 이번 검증에 포함하지 않았다.
  이전 역사 캐시는 콘텐츠 Hash가 달라 무효다. 구단 운영 경제의 장기 체감 밸런스는 별도 검증 영역이다.

이 보고서는 직전 `runtime-export-peak-gate-20260911.md`의 미발급 우회 처리보다 우선한다.
