# 역사 포지션 복원 — 연구 후보

> 전체 연도 포지션 보완의 최신 정본·검증·반영 절차는 [전체 시즌 포지션 재저작](SeasonPositionRevision.md)을 따른다.
> 아래 미게시 기록은 과거 강팀 밸런스 후보에 관한 이력이다.

## 상태

**강팀 재현 통과 전이며 공식 Runtime·역사 캐시는 게시하지 않았다.**
능력치 곡선의 기본값도 기존 center 45, slope .45를 유지한다.
통과하지 않은 후보를 최종 밸런스로 사용하지 않는다.

## 원인과 변경

로스터 선정 단계에서 실제 수비 기록으로 확인한 부포지션이 경기 Player 생성까지 전달되지 않았다.
이제 `secondaryPositions`가 Importer → Runtime DTO → Definition → 역사/구단주 경기 Player로 전달된다.
수비 자격은 기존 기준인 5경기 또는 45아웃 이상과 보충 포지션 근거를 사용한다.
자격이 확인된 부포지션의 적응도는 `qualifiedSecondaryPositionProficiency`에서 저작한다.
주 포지션·실제 수비 능력 자체를 일괄 상향하는 변경은 아니다.

결측 포지션 선수는 현재 경기에서 모든 수비 위치 적응도가 100이다. 알려진 선수에게는 실제
포지션 제약이 있으므로 대상 강팀만 조사하면 상대 팀의 결측 이점은 남는다. 1992 빙그레 23건에
더해 1985·1992 상대 12구단 296건을 같은 방식으로 조사했다. 이적 구단이 맞지 않는 3건은 제외했다.
`season_position_research_1985_1992.json`에 원문 URL·시즌별 선수 목록,
`season_position_research_1985_1992_audit.json`에 연결 제외 내역이 있다.

출처는 시즌별 위키백과 선수단 목록인 B등급 근거다. 포지션만 보충하며 이닝·경기 수·능력치·
선발/구원 보직을 그 목록에서 추측하지 않는다. 원본 수비 기록이 있으면 그것을 우선한다.
[1992 빙그레 시즌 목록](https://ko.wikipedia.org/wiki/1992년_빙그레_이글스_시즌)과
[1985 해태 시즌 목록](https://ko.wikipedia.org/wiki/1985년_해태_타이거즈_시즌)을 포함한 13개 출처를 사용했다.

최종 후보는 17,333시즌에 필드를 직렬화하고 2,844시즌에 유효한 부포지션이 있다.
선수 신원·원기록 수치·수상자·카드 ID는 보존된다. 13구단의 Core25 선정이 바뀐다.
현재 Runtime 대비 포지션 247건, 결측 플래그 318건, 로스터 역할 156건, Cost 5건도 바뀐다.
Cost 5건은 게시 도구의 허용 범위를 벗어나므로 자동 게시하지 않는다. 별도 변경 원인 검토가 필요하다.

## 실험 결과

동일 32개 시드, 팀당 144경기, 고정 5선발, 실제 Detailed 시즌 경로다.
실제 승률은 검증에만 사용했고 팀 이름별 보너스나 결과 덮어쓰기는 넣지 않았다.
아래 순위는 32시드 평균 승률 순위이며 매 시드 우승을 뜻하지 않는다.

| 후보 | 85 삼성 | 92 빙그레 | 10 SK |
|---|---:|---:|---:|
| 실제 승률 | .706 | .653 | .641 |
| 현재 기준선 | .522 / 2위 | .542 / 2위 | .523 / 3위 |
| 양쪽 구단 포지션 복원 | .525 / 3위 | .550 / 2위 | .543 / 2위 |
| 복원 + 공통 기울기 1.0 | .564 / 2위 | .590 / 2위 | .601 / 2위 |
| 복원 + 타자 1.0 / 투수 1.5 | .534 / 3위 | .591 / 2위 | .587 / 2위 |

곡선 후보는 입력 70의 변환값을 유지하도록 offset을 함께 바꿨다. 후보 기본값 적용은 보류했다.
타순 AI를 연결한 별도 실험도 통과하지 못해 해당 연결은 되돌렸다.
9개 실험 총 464,917경기, 각 실험의 3개 연도 첫 시드 결정론 재실행은 일치했다.
회귀 테스트는 Core 부포지션 4, 곡선 5, 역사 Builder 26, Importer 부포지션 2,
Runtime 베이크 12, 통과 판정 6으로 총 55건 통과했다. Unity Editor·PlayMode 검증은 아니다.

승률 ±.03과 동년 최강팀 평균 1위를 잠정 통과 기준으로 계산하면 **어느 후보도 3개 대상 중 통과가 없다.**
전체 역사 상위 30개 검증은 미완료다. 동년 복수 대상에게 모두 단독 1위를 요구할 수 없으므로
검증 도구는 동년 최강팀 1위, 나머지는 실제 상대 순서를 확인한다. 이 해석과 허용 오차는 사용자 확정 전이다.

## 입력 고정과 다음 결정

- 기준선 해시: `6e3d993e1785767b5c065972048f407f76772ce5e2fdbb62c49d9c2c97bf36d7`
- 최종 후보 해시: `4606b990756346a62a774905dbef7c62ec18683d811cdf72efb2736867115f95`
- 게시 전 확인한 현재 해시: `4d2c3507edd70b54d7f87953e5ab98d45f6cebb82c3a9b2f0e6daa086d510705`

작업 중 다른 Runtime 변경이 확인되었다. 위 기준선과 최신 Runtime은 같지 않으며,
모든 차이를 이번 수정의 단일 인과 효과라고 해석하면 안 된다. 최신 기준선 재실행과
Cost 5건 검토 없이 후보 전체로 현재 데이터를 덮어쓰지 않는다.

남은 주요 가설은 기용 비중이다. 기존 프로젝트 42.16절은 실제 GS·이닝 가중 배분을 금지하고
모든 선발에게 29·29·29·29·28경기를 배분한다. 따라서 실제 에이스 집중 기용과 단기 출전자의
제한된 시즌 기여를 그대로 재현할 수 없다. 역사 베이크에 한해 원기록 기반 기용 비중을
허용하는 대조 실험은 기존 계약 변경 승인을 받은 뒤 진행한다. 그것만으로 통과한다고 단정하지 않는다.
