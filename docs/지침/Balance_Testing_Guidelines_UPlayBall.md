# 밸런스 테스트 도구 지침

> 출처: `BaseballManager_PROJECT.md` 28절 (2026-08-28 `docs/지침`로 이동)

이 프로젝트에서는 개발용 시뮬레이션 툴이 매우 중요하다.

예:

```text
10경기
100경기
1,000경기
10,000경기

자동 실행
```

결과:

```text
리그 평균 타율
리그 평균 ERA
경기당 홈런
경기당 득점
볼넷 비율
삼진 비율
도루 성공률
```

목표 수치에서 지나치게 벗어나면 확률 모델을 수정한다.

게임 UI보다 먼저 개발해도 되는 핵심 개발 도구다.

대량 시뮬레이션은 매 작업 실행마다 수행하지 않는다. 밸런스 계수를 바꿨을 때, 또는 필요하다고
판단되거나 요청받은 경우에만 실행한다.
