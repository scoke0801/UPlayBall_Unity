1. 기능 정의

“내 구단이 KBO 역사 속 강팀을 어디까지 꺾을 수 있는가”를 검증하는 상시 PvE 도전 콘텐츠다. 정규 일정과 분리하여 즉시 경기할 수 있고, 과거 강팀의 대표 선수와 팀컬러를 경험하게 한다.

핵심 루프
상대 선택 → 전력/선발 확인 → 경기 → 승패 저장 → 상대 선발 교대 → 3승 최초 보상 → 다음 순위 해금
기본 결정안
팀별 누적 3승. 패배해도 승수는 유지한다. 상대 선발은 경기 시도마다 1→5 순환하며, 중도 이탈·스킵 완료도 1경기로 처리한다.
콘텐츠 위치
메인 로비 → 경기 → 연습경기 → 역대 강팀. 구단주 모드에서만 노출한다.
완주 목표
100팀 × 팀별 3승 = 최소 300승. 10개 구간으로 묶어 장기 진행도와 단기 목표를 함께 제공한다.

2. 레퍼런스 해석

원작 프로야구매니저는 선수 카드와 연도별 실제 데이터를 바탕으로 라인업을 관리하고, 구성한 팀 데이터로 경기를 자동 시뮬레이션했다. 당시 연습경기는 반복 가능한 별도 경기이자 구단 자금 획득 수단으로 언급된다. 본 기획은 이 “준비 후 관전·결과 확인” 리듬만 계승하고 UI와 규칙은 프로젝트용으로 재설계한다.

취할 점프로젝트 적용복제하지 않는 점
연도별 선수 카드와 라인업시즌 팀 스냅샷과 대표 카드원작 로고·UI 자산
준비→자동 경기→결과상대 정보→경기/스킵→결과온라인 시간제 리그
연습경기 반복 보상팀별 3승 최초 보상무제한 재화 파밍
자료 한계: 공개 자료로 원작 연습경기의 세부 규칙까지 완전 복원되지는 않는다. 아래 UI는 원작의 정보 밀도와 관리 게임 감성을 참고한 독자 시안이다.

4. Bake 데이터와 상위 100팀 선정

승률만 단순 비교하면 표본 수·홈/원정·상대 강도에 따라 순위가 흔들린다. 모든 후보가 동일 조건에서 충분한 경기를 치른 결과만 랭킹에 투입한다.

단계처리검증
후보 생성시즌별 엔트리·규칙·구장·리그 환경을 스냅샷으로 고정HistoricalTeamCandidate[]
라인업 생성포지션 적합, 동일 인물 중복 금지, 엔트리 규칙 적용Invalid roster 0건
리그 Bake후보 간 균등 대진, 팀당 최소 1,000경기, 홈/원정 50:50승패무·득실점·seed·버전
순위 안정화동률은 경기 수→경기당 득실차→ID. Wilson 하한은 보조 기록동일 seed 결과 해시 일치
100팀 확정상위 100개를 정적 asset/json으로 export. 런타임 재정렬 금지rank 1~100 유일
권장: 랭킹용 bakedWinRate와 화면에 보여줄 실제 시즌 승률 officialWinRate를 분리한다.
  • 시뮬레이션 로직·능력치 환산·팀컬러 효과 변경 시 simulationVersion을 올리고 전량 재Bake.
  • challengeTeamId는 영구 ID. 순위가 바뀌어도 기존 보상 수령 기록은 팀 ID 기준 유지.

5. 역사 팀 라인업 구성

각 팀은 강함과 역사적 기억을 함께 재현한다. 레전드·커리어하이·레어 카드를 포지션과 팀컬러 발동을 만족하는 범위에서 우선 배치한다.

슬롯우선순위제약
주전 야수 9명커리어하이 → 레전드 → 레어 → 일반전 포지션 유효, 동일 인물 1장, DH 규칙
선발 5명시즌 이닝/선발 기여도 + 등급선발 적성 필수
불펜/마무리보직 적합도 → 시즌 기여도필승조·추격조 최소 인원
벤치대타/대주자/포수 백업포지션 커버리지 우선
팀컬러시즌/구단 팀컬러 최고 단계실제 조건 계산, 강제 플래그 금지

LEGEND 상징성 CAREER HIGH 선수 최고 시즌 RARE 희소 변형. 여러 조건에 해당해도 엔트리에는 한 장만 들어간다.

selectionScore = positionFit × 100 + seasonContribution × 10 + cardTierWeight + teamColorContribution - duplicatePenalty 검증: Starting9Valid && RotationCount == 5 && CatcherCount >= 2 && DuplicatePersonCount == 0 && ActivatedTeamColorTier >= targetTier

10. 예외 처리 및 수용 기준

상황처리
경기 중 강제 종료결과 미확정이면 미진행 복구. 확정 저널이 있으면 1회 반영.
무승부승수 미증가, 시도/무승부 증가, 상대 선발 순환.
3승 직후 종료RewardReady 저장, 재접속 후 수령.
지급 중 종료트랜잭션 ID로 재시도, 중복 지급 금지.
카드 삭제/변경baked snapshot 사용 또는 해당 팀 비활성.
완전 동률영구 ID 오름차순.
  1. Catalog에 정확히 100팀, rank 1~100 중복·누락 0.
  2. 모든 팀의 엔트리·5선발이 유효하고 지정 팀컬러가 실제 조건으로 발동.
  3. 같은 seed/version에서 Bake 결과 해시 재현.
  4. 승리 3회 누적 시 다음 팀 해금 및 최초 보상 1회 생성.
  5. 승·패·무 모두 상대 선발 1→2→3→4→5→1 순환.
  6. 재접속·강제 종료·지급 재시도에서 중복 반영 0.
  7. 100개 목록 가상화 및 키보드·마우스·게임패드 전체 조작.
