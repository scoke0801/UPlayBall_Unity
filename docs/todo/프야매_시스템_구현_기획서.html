04 / SUPPORT CARD

서포트 카드

원작 근거 팀 계통 최대 1장, 선수 계통 기본 3장, 선수 1명당 1장, 약 2일 지속. 컨디션·전력분석·능력치를 조건별로 상승시킨다.

적용안 시즌 중 단기 전략 카드. 효과는 다음 2경기 지속이며 자동으로 소모된다. 팀 1슬롯 + 개인 3슬롯을 기본 제공한다.

05 / SLOGAN

슬로건

원작 근거 특정 선수 보유·라인업 도전과제로 해금하며, 좁은 조건의 선수군에 능력 상승과 일부 하락을 함께 부여한다.

적용안 덱 방향성을 선언하는 상시 패시브. 시즌 시작 전 1개 선택, 시즌 중 교체 불가. 레벨 1~6은 도전과제로 상승한다.

해금

요구 카드 보유, 특정 기록, 리그 달성 조건 중 하나 이상. 진행도를 항상 노출한다.

적용

TargetQuery에 맞는 등록 선수에게만 적용. 상승·하락을 카드 상세에 함께 표시한다.

성장

Lv.1/3/5는 효과량, Lv.2/4/6은 적용 범위나 페널티 완화 중 데이터로 지정한다.

대표 적용안

슬로건대상효과 Lv.1 → Lv.6해금 예
지지 않는 야구체력 70+ 불펜제구 +1→+4 / 구속 -1→0불펜 3명 20홀드

06 / STAFF

감독·수석코치·코치

원작 근거 수석코치는 조건에 맞는 1군 선수의 컨디션을 일정 기간 올리고, 코치는 선수를 등록해 추가 효과를 제공하는 운영 축이다.

적용안 스태프 슬롯을 역할별로 분리한다. 감독은 팀 전술, 수석코치는 컨디션 관리, 타격/투수/수비 코치는 성장 보정에 관여한다.

슬롯핵심 효과발동 시점중복
감독 1경기 운영 성향·작전 빈도경기 시뮬레이션 시작슬로건과 가능
수석코치 1조건형 컨디션 +1~2주간 시작동일 코치 재사용 불가
전문코치 3훈련 효율·특정 스탯 경험치주간 훈련 정산동일 카테고리 최고값
주의: 카드 한 장이 능력치·컨디션·경기 AI를 동시에 바꾸지 않도록 책임을 분리한다. 효과 출처를 알 수 없는 ‘전력 상승’ 표시는 금지한다.
07 / SKILL BLOCK

스킬 블록

원작 근거 C~S 등급 블록을 선수의 스킬 공간에 배치하여 능력치를 올리고, 생산·조합·슬롯 개방으로 장기 성장을 만든다.

적용안 오프시즌 전용 퍼즐형 성장. 선수별 4×4 보드에 블록을 회전·배치한다. 등급보다 모양과 시너지가 선택을 만들도록 한다.

보드 규칙

  • 초기 6칸 개방, 전지훈련으로 최대 16칸.
  • 블록은 1~4칸 모양, 회전 가능, 겹침 불가.
  • 같은 태그 3개 인접 시 세트 보너스.
  • 구매·장착·해제는 오프시즌에만 가능.

획득 규칙

  • 연구 1회: PT 소비, C~A 2개 확정.
  • 연구 누적 10회: S 선택 상자 1개.
  • 낮은 등급 5개 → 같은 계열 상위 1개 합성.
  • 결과 등급 확률은 실행 전에 공개.

카드 표시

선수 카드 하단에 보드 등급 아이콘 1개만 표시한다. C=청동, B=은, A=금, S=백금. 상세 화면에서는 블록별 상승량과 세트 효과를 펼쳐본다.

08 / OVERSEAS TRAINING

해외 훈련 (원작 유학)

원작 근거 나이·카드 종류·리그 성과에 따라 훈련지가 열리고, 6/12일 동안 특화 능력치를 성장시킨다. 성공·명인·실패 결과가 존재한다.

적용안 오프시즌 4주 중 선수를 1~3주 파견한다. 완전 실패를 제거하고 기본 / 대성공 2단 결과로 단순화한다.

  • 취소 시 시작 전 100%, 진행 후 50% 환급하며 성장 없음.
09 / STAT CORRECTION

능력치 교정

원작 근거 불필요한 기본 능력치를 낮춰 원하는 능력치로 옮긴다. 총합은 유지되고 카드당 3회, 기본치 구간별 증감 한계가 존재한다.

적용안 랜덤 인스트럭터 결과를 제거하고, 오프시즌에 사용자가 직접 감소 1개 + 증가 1개를 선택한다. 카드당 커리어 3회.

10 / TRAINING PARTNER

훈련 파트너 (원작 멘토링)

원작 근거 멘토·멘티 1:1 연결, 최대 다수 쌍, 나이·출신·구단·포지션·능력치 차로 궁합과 상승량을 산정한다.

적용안 명칭을 ‘훈련 파트너’로 바꾸고 오프시즌 전용 영구 성장으로 운영한다. 한 오프시즌에 선수당 한 번만 연결 가능하다.

추천 점수

Fit = AgeGap×0.20 + SamePosition×0.25 + SameTeamHistory×0.15 + StatComplement×0.30 + Personality×0.10
GrowthBudget = floor((1 - PotentialRate) × 15 × Fit)
추천 정렬은 총합만 보지 않고 선수 역할에 유효한 스탯 가중치를 적용한다. DH에게 수비만 올리는 추천 같은 역효과를 차단한다.

화면 구성

좌측중앙우측
성장 대상 선수·잠재력추천 파트너 3명과 궁합 근거예상 성장, PT 비용, 역할 적합도
  • 동일 선수는 같은 오프시즌에 멘토/멘티 역할 중 하나만 가능.
  • 확정 시 PT 차감과 성장 반영을 한 트랜잭션으로 처리.
  • 추천 후보가 없으면 부족 조건을 구체적으로 표시한다.
11 / TRAINING CAMP

전지훈련

원작 근거 2군 선수를 훈련장에 보내 경기마다 스킬 칸 경험치를 얻는다. 훈련장별 속도·비용이 다르고 완료 후 직접 복귀한다.

적용안 오프시즌 시설에 선수를 배치해 스킬 보드 칸을 개방한다. 실시간 대신 주차 단위이며, 자동 복귀 옵션을 기본 ON으로 둔다.

저장과 일정 처리

결정적 결과 보장: 훈련 확정 시 결과 시드를 저장한다. 저장 후 재로드로 대성공 결과를 반복 추첨할 수 없어야 한다.
  1. 명령 요청 시 현재 시즌 단계, 비용, 선수 상태를 재검증한다.
  2. PT 차감·아이템 소비·성장 상태 변경을 하나의 커밋으로 저장한다.
  3. 주차/경기 진행 시 모든 만료와 완료를 처리한 뒤 새 세이브를 만든다.
  4. 버전 필드를 두고 테이블 개편 시 Modifier 출처 단위로 마이그레이션한다.

15 / QA

통합 검수 체크리스트

기능

  • 모든 실행 버튼이 시즌 단계와 선수 상태를 동시에 검증한다.
  • PT 부족 시 어떤 값도 부분 변경되지 않는다.
  • 동일 Modifier가 중복 등록되지 않는다.
  • 카드 상세 합계와 경기 적용 값이 일치한다.
  • 만료·귀환·개방 알림이 한 번만 발생한다.

경계값

  • 스탯 1/상한, 컨디션 최저/최고
  • 오프시즌 마지막 주와 기간 초과 훈련
  • 보유 PT가 비용과 정확히 같은 경우
  • 선수 방출·2군 이동·라인업 해제
  • 세이브 직후 종료 및 구버전 로드

공통 인수 기준

  1. 사용자는 확정 전에 비용, 대상, 기간, 최종 변화를 확인할 수 있다.
  2. 사용자는 선수 카드에서 모든 성장 출처를 역추적할 수 있다.
  3. 잠긴 기능은 비활성화 사유와 해금 조건을 함께 보여준다.
  4. 오프시즌 종료 시 진행 중이거나 미사용인 핵심 행동을 경고한다.
  5. 키보드·게임패드만으로 모든 슬롯 선택, 비교, 확정, 취소가 가능하다.
자료 기준 · 사용자가 제공한 「프로야구 매니저/게임 설명」 발췌문(서포트 카드~전지훈련). 원작 수치와 운영 방식은 역사적 레퍼런스로만 사용했으며, 적용안 수치는 UPlayBall 프로토타입 밸런스 초안이다. 실제 플레이테스트 후 PT 수급량과 시즌 길이에 맞춰 조정한다.
