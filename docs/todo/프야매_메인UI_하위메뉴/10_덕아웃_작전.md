## 목표 동작

필터 → 카드 → 상세/Counter → 슬롯 → 충돌 검증 → 확정 → 경기 준비 Loadout.

- 진입 시 실제 Snapshot을 Bind하고 선택 변경은 View State로 관리한다.
- Command 전에 Preview/검증 결과를 표시하고 성공 후 Runtime Snapshot을 다시 Bind한다.
- Loading/Empty/Locked/Insufficient/Invalid/Error 상태를 같은 Content 영역에서 설명한다.
- Back은 진입 원점과 선택·필터·Scroll 상태를 복원한다.

## ImageGen 정의

화면 구현에 필요한 래스터 디자인은 built-in ImageGen으로 생성해 프로젝트 자산으로 연결한다.

유형별 공통 Frame과 실루엣은 자산별 stylized-concept. 카드 문구는 Native UI.

- 실행 방식은 built-in ImageGen이다.
- 입력 이미지는 reference image로 명시하며 원본 파일을 런타임 자산으로 복사하지 않는다.
- 결과물에는 텍스트, 실제 구단 로고, 상표, 워터마크를 넣지 않는다.
- Panel/Button/Table은 생성하지 않고 Native uGUI로 조립한다.
- 서로 다른 자산은 각각 별도 ImageGen 호출로 만든다.
- 구현 시 최종 프롬프트, 생성 결과, 프로젝트 저장 경로를 이 파일에 기록한다.
