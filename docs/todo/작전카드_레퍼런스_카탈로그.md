# 작전카드 레퍼런스 카탈로그

## 0. 이 문서의 성격

이 문서는 **새 작업 명세가 아니라 콘텐츠 참고 자료**다. `docs/디자인/ref/`의 프야매 계열 작전카드
이미지(`공통작전카드_ref.png`, `공통특수작전카드_ref.png`, `야수작전카드_ref.png`,
`야수작전카드_2_ref.png`, `야수_작전카드_특수_ref.png`, `투수작전카드_ref.png`)에 있는 카드 44종의
이름·발동 조건·상성을 텍스트로 옮긴 것이다.

이 카탈로그의 용도는
[06_전술카드_시스템.md](역사시뮬레이션_구단주모드/06_전술카드_시스템.md) §6 "1차 구현 전술카드 16장"과
§12 콘텐츠 게이트(`NewGameDefinition.asset`에 실제 카드가 2장뿐)를 채우는 **원본 소재**다. 이 문서
자체는 `TacticCardDefinition` SO를 만들지 않는다 — 실제 데이터 저작과 수치(`ProjectBalanceValue`)
확정은 06번 문서의 완료 게이트를 따른다.

파일명 주의: 원본 이미지 `야수_작전카드_특수_ref.png`는 이름과 달리 **투수 계열 카드**(§4 참고)를
담고 있다. 아래 표는 실제 내용 기준으로 재분류했다.

## 1. 프야매 레퍼런스 체계와 프로젝트 Schema 대응

| 레퍼런스 등급 | 아이콘 | 효과 방향 | `TacticCardDefinition` 대응 |
|---|---|---|---|
| 일반카드 | ▲ | 조건부 자가 능력치 상승 | `TacticTier = Normal`, `StatModifiers[]` 양수 |
| 특수카드 | `!` | 상대 카드 계열 전체 무효화 | `IsDisruption = true`, `TacticTier = Special` |
| 황금카드 | ▼ | 상대 능력치 직접 하락 | `TacticTier = Rare`/`Special`, `StatModifiers[]` 음수, `CounterCardIds[]` 사용 |

레퍼런스의 "상쇄"는 서로가 서로의 `CounterCardIds`에 들어가는 대칭 관계, "무효화"는 한쪽이 다른 쪽의
`CounterCardIds`에만 들어가는 비대칭 관계로 옮긴다.

## 6. 06번 문서 1차 16장 목표와의 매핑 메모

06번 문서 §6이 이미 확정한 1차 16장 이름(초반 총공세, 클린업 폭발, 문을 닫아라, 끈질긴 승부 등)은
이 카탈로그의 44종과 **이름이 동일하지 않다.** 06번 문서 쪽이 프로젝트 자체 조어이고, 이 카탈로그는
프야매 원본 레퍼런스 그대로다. 콘텐츠 저작 착수 시 다음 중 하나를 먼저 결정해야 한다(06번 문서
"선행 설계 결정" 항목으로 옮길 것):

1. 06번 문서 §6의 16장 이름을 그대로 쓰고, 이 카탈로그는 효과·Trigger·Counter 설계의 참고 소재로만
   쓴다.
2. 이 카탈로그의 44종 중 대표 16장을 골라 §6 목록을 이 카탈로그 이름으로 교체한다.

이 문서는 그 결정을 내리지 않는다. 결정 후 실제 데이터 저작(`NewGameDefinition.asset` 등)과 수량
검증은 06번 문서의 완료 게이트를 따른다.

## 7. 미확인 항목

- 투수 계열 특수카드(`야수 작전 무효`에 대응하는 `투수 작전 무효`) 존재 여부 — 원본 레퍼런스 이미지에
  없음.
- `카드_디자인_ref.png`는 작전카드가 아니라 선수 카드(능력치/기록) 디자인 레퍼런스라 이 카탈로그에서
  제외했다.
