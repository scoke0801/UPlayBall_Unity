# 커리어·성장 안정화 기준선

기준일: 2026-08-30  
대상: 캐릭터 생성, 성장, Skill Board, 실제 경기 공식, 버전·설명 데이터

## 실행 결론

- Core 순수 C# 회귀: 10/10 통과
- Simulation 순수 C# 회귀: 140/140 통과
- Game 핵심 순수 경로: 성장 15개, 새 게임 9개, 리그 이동 7개, 계약 전환 9개 통과
- Core/Simulation/Game/Presentation/Editor와 대응 테스트 asmdef: 경고 0, 오류 0
- Unity PlayMode: 실행하지 못함. 이미 열린 Editor의 라이선스 채널과 BatchMode가 충돌했기 때문이다.

## 실제 경기 엔진 10,000경기

`MatchSimulationStatisticsTests`는 `MatchSimulator.Simulate`를 호출하고, 이 공개 경로는
`DetailedMatchEngine`으로 위임된다. 아래 값은 경량 대체 공식이 아니라 실제 커리어 경기 공식의 결과다.

| 지표 | 결과 |
|---|---:|
| AVG | .275 |
| OBP | .350 |
| SLG | .426 |
| 경기당 득점 | 3.79 |
| BB% | 9.2% |
| SO% | 17.4% |
| HR% | 1.54% |
| HBP% | 1.10% |
| 강팀 승률 | 73.2% |
| 무승부 | 99/10,000 |

Unique Contact +4 비교 5,000경기에서는 강화 타선 AVG .288, 기준 타선 AVG .279가 나왔다.
능력치 민감도 방향과 승률 우위가 유지된다.

이 모드는 실제 성장·노쇠·역할 평가기를 사용하지만 경쟁자를 고정한 성장/역할 전용 선행 진단이다.
리그 월드·계약·경제 분포를 증명하는 전체 커리어 코호트로 해석하지 않는다.

출장 0에도 DevelopmentProgress가 남고, 같은 입력에서는 주전의 Base 상승 환산 누적 진행도가
백업보다 큰 것을 회귀 테스트로 고정했다. Base가 오르면 진행도 1,000이 차감되므로 잔여 진행도만
비교하지 않는다.

## 변경 후 검증된 계약

- 생성 규칙 원장 한 개
- 생성 Potential 숨은 RNG 없음
- Base Ability가 Potential을 넘지 않음
- 기존 초과 Base를 마이그레이션해 유효 능력 보존
- Peak Bonus 0~3
- DevelopmentProgress 정수 이월
- Skill Bonus 능력치별 +9, 전체 +18
- 같은 능력치 스택 100%/60%/30%/0%
- 개막일 ActiveSkillBoardSnapshot 고정
- 리그별 Skill Gacha 구매 제한
- 같은 Seed·입력·SimulationVersionStamp 재현
- 부상·역할·계약·은퇴 판정의 Explanation 반환
- 기본 성장 콘텐츠 정적 검증 오류 0건

## 해석과 남은 위험

경기와 성장 단위 밸런스는 안정화 변경 뒤에도 기준 범위에 있다. 다만 이것만으로 20시즌 월드의
리그 체류, 역할 복귀, 경제, 계약, 은퇴 분포를 증명하지는 못한다. 실제 1,000명×20시즌 정기 코호트와
PlayMode UI 입력·포커스·해상도 매트릭스는 별도 장시간 검증으로 남아 있다. 이 두 항목을 통과하기
전에는 Career Stabilization 전체가 출시 완료됐다고 판정하지 않는다.
