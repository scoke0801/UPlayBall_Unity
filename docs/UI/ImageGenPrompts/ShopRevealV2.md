## 상점 Navigation Icon

- 용도: Owner 상단 `상점` 메뉴 48~64 px Icon
- 최종 프롬프트: `Use case: product-mockup. Asset type: transparent Unity navigation icon for the Shop menu. Primary request: create one compact premium baseball management game shop icon that reads instantly at 48–64 px. Input images: Image 2 is the primary style and scale reference for the existing top navigation icons; Images 1 and 3 provide the shop and baseball-card context. Subject: a small front-office shop counter or shopping bag combined with one baseball card pack and a baseball, arranged as a single clear emblem. Style/medium: polished early-2000s Korean PC baseball management game icon, small isometric painted render, crisp silver edges, navy and muted royal-blue accents, restrained warm gold highlight. Composition/framing: centered compact silhouette, generous transparent padding, readable at tiny size, no separate background plate. Lighting/mood: professional front-office, subtle top-left studio light. Constraints: genuinely transparent background; no text; no letters; no numbers; no real team logo; no trademark; no watermark; no UI button frame; no glow bloom; no neon; no photoreal person.`
- 결과: `Assets/10.Datas/Resources/UI/Shop/shop_navigation_icon_v2.png`
