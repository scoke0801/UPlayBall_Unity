# 구단 Cost와 실제 KBO 성적 비교

분석일: 2026-09-05. 현재 배포된 Ability v6 / Cost v9 / DerivationBalance v12 데이터를 사용했다.

## 판단

현재 구단 Cost는 같은 시즌 강팀·약팀을 구분하는 데 유용하지만, 가까운 전력의 순위를 정밀하게
설명하기에는 부족하다. 연도 평균을 제거한 Cost–승률 Pearson r은 **0.746**이며 최근 10시즌은
**0.819**다. 반면 현재 구단 능력치 평균인 `referenceStrength`는 각각 **0.872 / 0.901**로
Cost보다 실제 성적과 더 잘 맞는다. Cost를 가격·편성 제한에 사용하고 전력 표시는 능력치를
기반으로 판단하는 방향이 이 자료에서는 더 타당하다.

## 데이터와 방법

- 실제 게임 Archive: `Assets/10.Datas/HistoricalSimulation/1982-2025/`.
- 실제 역사 성적: `Tools/KBOImporter/.cache/KBOImport/Normalized/1982.json` ~ `2025.json`.
- 44개 연도, 363개 구단 시즌. 모든 Source–Runtime 구단 ID 연결 및 44개 Runtime 연도 파일의
  manifest SHA-256 일치를 확인했다. 실시간 KBO 사이트 재수집·원문 대조는 수행하지 않았다.
- 구단 Cost: `RosterCostResolver`와 동일하게 Core25 중 주전 타자 9명 + 투수 11명의 Canonical
  Cost 합계. 벤치 타자 5명 제외. 모든 구단에서 9+11 구성과 25개 카드 중복 없음을 확인했다.
  초기 시즌의 명시적 Replacement도 현재 배포 로스터의 일부이므로 포함했다.
- 모든 구단의 저장 승·패·무 합계가 경기 수와 일치하고 저장 승률이 있는지 확인했다.
- 주 결과는 저장된 `sourceWinPct`를 사용한다. 승률 규정의 시대 차이를 확인하기 위해
  `W/(W+L)`로 통일한 민감도 분석도 수행했으며 r=0.747로 결론이 유지됐다.
- 연도별 평균을 뺀 Cost와 승률 사이 Pearson 상관을 계산했다. 연도별 Spearman 상관은
  동률에 평균 순위를 부여한 뒤 44개 연도의 상관을 동일 가중 평균했다.
- 원본 `rank`는 승률 정렬과 다르며 분리 리그도 있다. 46개 연도·리그 그룹 내부에서 별도로
  분석했고 평균 Spearman은 0.666이다. 원본 rank와 승률 순서가 반대인 구단 쌍은 36개였다.
  이를 자료 오류로 단정하지 않으며 승률 순위와 원본 순위를 구분한다.

## 전체 결과

| 지표 | 1982~2025 | 2016~2025 |
|---|---:|---:|
| 구단 시즌 수 | 363 | 100 |
| 20인 Cost–승률 Pearson, 연도 평균 제거 | 0.746 | 0.819 |
| 20인 Cost–승률 Pearson, 연도 구분 없이 합침 | 0.661 | 0.813 |
| 연도별 Cost–승률 Spearman 평균 | 0.671 | 0.747 |
| Cost 순위와 승률 순위의 평균 절대 차이 | 1.38위 | 1.49위 |
| 순위 차이가 1 이하인 구단 비율 | 59.8% | 56.0% |
| 최고 Cost 구단 중 최고 승률 구단이 있는 연도 | 19/44, 43.2% | 5/10, 50.0% |
| Cost 높은 구단이 실제 승률도 높은 구단 쌍 | 1,011/1,286, 78.6% | 349/431, 81.0% |

구단 수가 시대별로 다르므로 최근 순위 오차가 조금 크다는 사실만으로 최근 평가가 더 나쁘다고
볼 수 없다. 최고 Cost 적중은 동률 최고 Cost 중 하나만 최고 승률이어도 성공으로 센다.
구단 쌍 비교에서는 Cost 동률과 승률 동률을 제외한다. 쌍들은 서로 독립된 표본이 아니다.

연도 평균 제거 후 단변량 선형 적합의 r²는 55.7%다. 이는 동일 자료에서 관측된 승률 편차의
선형 설명 비율이며, 미래 예측 정확도나 시뮬레이션 재현율이 아니다. 같은 적합에서 Cost 10 차이는
승률 약 0.082 차이에 대응하지만, 이를 Cost 증가의 인과 효과나 모든 구단에 적용되는 공식으로
사용해서는 안 된다.

## Cost 차이가 작을 때의 한계

| 같은 연도 두 구단의 Cost 차이 | 높은 Cost 구단의 승률도 더 높았던 비율 | 비교 쌍 |
|---|---:|---:|
| 1~4 | 55.4% | 363 |
| 5~9 | 75.3% | 369 |
| 10~19 | 95.1% | 427 |
| 20 이상 | 99.2% | 127 |

이는 두 구단의 **시즌 승률 순서가 일치한 비율**이다. 서로 맞대결했을 때의 승리 확률이 아니다.
Cost가 1~4 차이인 구단은 현재 지표만으로 우열을 강하게 표시하기 어렵다.

## 시대별 차이

| 시대 | 구단 시즌 | 연도 평균 제거 Pearson | 연도별 Spearman 평균 |
|---|---:|---:|---:|
| 1982~1989 | 52 | 0.610 | 0.481 |
| 1990~1999 | 79 | 0.753 | 0.606 |
| 2000~2009 | 80 | 0.803 | 0.776 |
| 2010~2019 | 92 | 0.772 | 0.737 |
| 2020~2025 | 60 | 0.820 | 0.750 |

1984년과 1999년의 Spearman은 각각 -0.058 / -0.036으로 순위 구분이 거의 되지 않는다.
특히 1999년 Pearson은 0.733인데도 Spearman은 음수다. 따라서 전체 상관 하나만으로 개별 시즌
평가를 보증할 수 없다. 시대별 평균 Cost 자체도 다르다(1982년 121.3, 2025년 137.8).
이번 결과는 과거 강팀과 현대 강팀의 맞대결 전력을 검증한 자료가 아니다.

## 평가 지표 비교

아래는 모두 연도 평균을 제거한 실제 승률과의 Pearson 상관이다. 능력치 평균은 타자는 타자
6개 능력치, 투수는 투수 6개 능력치를 평균한 뒤 선수 간 동일 가중 평균한 값이다.

| 구단 평가 지표 | 전체 44시즌 | 최근 10시즌 |
|---|---:|---:|
| 주전 타자 9명 Cost | 0.612 | 0.654 |
| 투수 11명 Cost | 0.586 | 0.696 |
| 주전 타자 9명 + 투수 11명 Cost | 0.746 | 0.819 |
| 벤치를 포함한 25명 Cost | 0.758 | 0.828 |
| 20명 능력치 평균 | 0.871 | 0.893 |
| 25명 능력치 평균 | 0.872 | 0.901 |
| 저장된 referenceStrength | 0.872 | 0.901 |

벤치 포함만으로 개선되는 폭은 작다. 동일한 20명끼리 비교해도 능력치 평균이 더 잘 맞으므로,
Cost의 가격 구간화·출전량·역할별 평가가 전력 정보와 차이를 만든다는 해석이 가능하다.
다만 각 요인의 기여를 분리한 실험은 아니므로 단일 원인으로 확정하지 않는다.

최신 Cost는 능력치의 단순 평균이 아니다. 타자 기록 quality는 타율 45%, 장타율 25%, 홈런 25%,
도루 5%이며 투수는 ERA 75%, BB/9 25%다. 여기에 출전량, 시즌 길이, 역할 보정 및 9/10 자격
기준이 적용된다. 능력치 역시 해당 시즌 기록에서 만들어지며 ERA가 여러 투수 능력치에 반영된다.
따라서 이번 분석은 같은 시즌 성적의 사후 설명력 비교이며 독립적인 예측 검증이 아니다.

## 개발 판단과 검증 범위

현재 Cost를 전력의 대략적인 지표로 쓰는 것은 타당하다. 그러나 정확한 순위나 기대 승률처럼
표시하는 것은 근거가 부족하다. 기존 referenceStrength를 전력 지표의 우선 후보로 두되,
그 지표 역시 실제 DetailedMatchEngine 경기 성적을 잘 설명하는지는 별도 검증이 필요하다.
과거 시즌, 특히 1980년대와 위 순위 역전 구단을 개선 검증 집단으로 유지하는 편이 좋다.

게임 코드·밸런스·Bake 데이터는 변경하지 않았다. 통계 집계 도구 실행, 상관 계산의 기본 검산,
연도 파일 해시 및 로스터·성적 연결 검사는 수행했다. Unity 컴파일, EditMode 테스트,
경기 시뮬레이션은 이번 역사 성적 비교 범위에 포함하지 않았다.

재현 명령(프로젝트 루트, Node.js 22 이상):

```powershell
node Tools/KBOImporter/report_team_cost_standings.mjs
```

전체 363개 행·연도별 통계·입력 파일 해시는 `docs/reports/team_cost_standings_data.json`에 있다.

## 후속 구현: 기본 전력 표시

사용자 승인에 따라 구단주 홈의 내 구단·다음 상대, 선수단 Inspector에 능력치 기반 기본 전력을
연결했다. `RosterStrengthResolver`는 현재 등록된 선수들의 시즌 기본 능력을 읽고 타자·투수
유형에 해당하는 6능력을 선수별 동일 가중으로 평균한다. 저장된 구단 참조 수치를 그대로
재사용하지 않으므로 등록 선수 구성이 바뀌면 다시 계산한다. 벤치도 기본 전력에는 포함한다.
빈 선수단은 미평가로 표시하며 누락 카드는 조용히 제외하지 않고 오류로 처리한다.

편성 비용은 별도 `RosterCostResolver`의 주전 9명+투수 11명 합계를 표시한다. 원본 Cost,
스카우트·판매·카드 보너스 정책과 경기 확률 계수는 변경하지 않았다. 기본 전력에는
훈련·Edition·팀컬러·컨디션을 포함하지 않으며 선수단 화면에 이 기준을 명시했다.
기존 커리어 능력치 화면과 Editor `ReferenceStrength`는 이미 능력치 기반이므로 유지했다.

검증 결과:

- 신규 `RosterStrengthResolverTests` 4개와 기존 `HistoricalRosterLeagueResolverTests` 18개를
  Headless NUnit 러너에서 실행해 22개 모두 통과했다.
- 현재 363개 Runtime 구단을 새 C# Resolver에 입력했다. 이전 분석의 능력치 평균과 불일치
  0건, Cost 불일치 0건이며 저장 ReferenceStrength와 최대 차이는 0.00003334(반올림)다.
  실제 승률과 연도 평균 제거 Pearson은 0.8719330645438이다.
- `Baseball.Game.Unity.csproj`, `Baseball.Game.Tests.csproj`, `Baseball.Presentation.Tests.csproj`
  (Presentation 참조 빌드 포함) 최종 보조 컴파일은 각각 경고·오류 0개다.
- Unity EditMode 통합 테스트 실행과 실제 화면 레이아웃 확인은 수행하지 않았으며,
  추가한 Game/UI 통합 테스트의 실행 통과를 주장하지 않는다.
- 경기 확률·능력치·Cost 계수를 바꾸지 않았으므로 이번에는 경기 시뮬레이션을 실행하지 않았다.

검증 시 Unity 생성 csproj에 신규 파일만 추가하는 임시 MSBuild targets를 사용했다.
공유 설정이나 생성 csproj를 수정하지 않았으며 Source/Runtime Bake와 Save 구조도 유지했다.
