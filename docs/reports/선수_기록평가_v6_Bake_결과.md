# 선수 기록 평가 v6 / Cost v9 Bake 결과

사용자 요청대로 평가 기준 수정과 Canonical Bake만 수행했다. 테스트, 컴파일,
Unity 실행, 경기 시뮬레이션 및 WorldHistory Bake는 실행하지 않았다.

## 평가 기준

| 능력치 | 기준 |
|---|---|
| 체력 | `25 + 75 × IP / 427⅓`, 25~100. 원본 1982~2025 최다 1282아웃 기준 |
| 구속 | 실측 `fastballVelocityKph`, 110km/h=25 → 170km/h=100 선형 분배 |
| 제구 | BB/9가 낮을수록 높게 평가 |
| 구위·변화구·투수 멘탈 | ERA가 낮을수록 높게 평가 |
| 교타 | 타율 |
| 장타 | 홈런 수 50% + 장타율 50% |
| 주력 | 도루 수 |
| 수비 | 수비율 65% + 9이닝당 실책 역방향 35% |
| 송구 | 기존 보살/9이닝·포수 도루저지율, 있는 항목만 사용 |
| 타자 멘탈 | 추가 타격 지표 없이 타율 재사용 |

절대 기준인 체력·구속을 제외한 지표는 해당 시즌 비교 집단의 표본 보정 Z를 사용한다.
최솟값 25, 중앙값 55, 최댓값 100이다. 체력의 25 하한과 구속의 110km/h 하한은 게임용
분배 기준이며 역사 기록이라고 주장하지 않는다. 구위·변화구·멘탈의 ERA 공통 사용을 반영해
설정의 단일 지표 영향력 상한을 35%에서 80%로 바꿨다.

실측 구속이 없으면 중립 55를 저장하며 삼진율로 대체하지 않는다. 따라서 이번 Source에서는
구속별 선수 차이를 실측으로 복원하지 못한다. 결측인 능력치는 Trace에
`NeutralWithoutEvidence`, 절대 기준은 `AbsoluteRecordAnchor`로 구분한다.
Runtime 스키마와 UI는 확장하지 않아 이 부가 근거는 Editor JSON에 남는다.

지표가 일부 없으면 그 가중치는 0이고 나머지 가중치를 재정규화한다. 모두 없으면 중립 55다.
실제 도루 0·실책 0은 유효 기록이며 결측으로 취급하지 않는다. AVG·SLG·ERA는 필요한 원시
분자/분모가 있으면 계산할 수 있지만, 결측 분자를 0으로 만들어 성적으로 사용하지 않는다.

Cost quality는 타율 45%·장타율 25%·홈런 25%·도루 5%, 투수는 ERA 75%·BB/9 25%다.
Cost에서도 결측을 제외하고 가중치를 다시 합산한다. 기존 출전량, 시즌 길이, 역할별 보정과
9/10 자격은 유지한다. 수비 기회 자료가 있다는 이유로 주던 정액 가산을 제거했다.
TrainingCeiling은 +3/최대 100이며 Runtime의 99 상한 검사도 같은 계약으로 맞췄다.

## 시대 비교

Core25 각 선수의 유형별 6능력 평균을 구단별로 평균한 데이터 지표다.
과거는 1982~2000 정규순위 1위, 최근은 2016~2025 정규순위 2·3위다.
원본에 분리된 순위표가 있으면 그대로 포함한다. 모든 과거 구단이 현대 2~3위와 동일해지도록
개별 보정한 결과가 아니며 실제 경기 승률·순위를 뜻하지 않는다.

Cost 10 증가를 포함한 분포 변화는 기록 평가 변경의 결과다. 경제 및 경기 밸런스가
개선됐다는 검증 결과는 아니다. 기존 WorldHistory는 이전 ContentHash의 경기 결과이므로
새 콘텐츠에서 그대로 적중하지 않으며, 이번 요청 범위에 따라 재생성하지 않았다.

재현 집계 도구는 `Tools/KBOImporter/report_rating_bake.py`다. 이 도구는 저장 JSON만 읽으며
테스트·경기를 실행하지 않는다. 이번 Bake는 기본 파생/원본 계약 검사를 포함하지만
`--verify-editor-assets` 추가 재로딩 검사는 실행하지 않았다.
