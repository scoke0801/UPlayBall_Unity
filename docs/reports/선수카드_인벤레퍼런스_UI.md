# 선수 카드 레퍼런스 UI 변경

## 기준

사용자 지정 [인벤 선수 카드 가이드](https://www.inven.co.kr/webzine/news/?news=86752&site=bm)의
야수 앞면과 투수 뒷면 원본 이미지를 확인했다. 저장소의 후기 MVP·골든글러브 카드 이미지보다
해당 기사의 초기 프야매 디자인을 우선했다.

## 반영 범위

- 구단주 상세 앞면: 228:320 비율, 얇은 은색 테두리, 어두운 초상화 배경, 검정 명찰과 연도,
  흰색 6능력치 막대, 하단 COST 별·숫자. 카드 종류는 명찰 색으로 구분한다.
- 구단주 상세 뒷면: 좌측 초상화·프로필, 우측 구종 또는 수비 위치, 하단 시즌 기록과 4×4 스킬 영역.
  실제 구종 수와 기록 필드, 스킬 보유 개수, 앞뒤 전환 입력을 유지한다.
- 공용 목록·라인업 카드: 검정·은색 표면과 밝은 글자, 명찰의 이름·연도, 하단 COST와 카드 종류.
  선택·경고·비활성·배치 배지 기능은 유지한다.
- 커리어 카드 앞면: 얇은 금속 테두리, 검정 명찰, 흰색 능력치 막대로 변경한다.
  커리어의 종합 능력을 구단주 COST로 바꾸지 않는다. 커리어 뒷면은 기존 구성이다.
- 공용 `PlayerCardSurface`는 UI 메시로 색상 그라데이션을 그린다. 신규 프레임 PNG는 사용하지 않는다.
- 통합 에디터 툴의 기존 카드 시각 검증에 앞면 출력도 추가했다.

## 제한과 검증 상태

원작 실사 선수 사진·실제 구단 로고는 도입하지 않았고 기존 프로젝트 초상화를 사용한다.
계약 잔여일·컨디션 추세·능력치 보정분·수비 적성 등급 등 현재 카드 Snapshot에 없는 값은
임의로 표시하지 않는다. 스킬 영역은 기존 데이터가 제공하는 개수와 소켓 안내를 유지하며,
장착된 블록의 실제 배치 모양을 새로 구현한 것은 아니다.

시뮬레이션·능력치 수치·세이브 구조는 변경하지 않았다. 변경 파일의 `git diff --check`는 통과했다.
보조 컴파일은 병행 작업 중인 커리어 저장 설정의 참조/partial 파일 문제로 완료되지 않았다.
Unity 렌더링은 다른 작업의 프로젝트 점유로 실행되지 않아 결과 PNG를 생성하지 못했다.
이후 사용자가 테스트를 직접 수행한다고 지시하여 추가 컴파일·테스트·Unity 실행을 중단했다.
따라서 이 보고서는 코드 변경 내역이며 실제 화면 검증 및 레퍼런스 일치도 검수 완료 보고가 아니다.
