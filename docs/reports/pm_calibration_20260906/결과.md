# 프야매 Cost·기록 평가 개선 결과

현행 산식을 **Ability v7 / Cost v10 / DerivationBalance v13**으로 갱신했다.
선수 이름·구단·특정 시즌별 예외는 없으며 모든 보정값은
[`derivation_balance.json`](../../../Tools/KBOImporter/derivation_balance.json)에서 조정한다.
1982~2025년 Source 17,333개와 Replacement 54개를 재생성하고 실제 Editor/Runtime 데이터에 반영했다.
**WorldHistory 캐시는 생성하지 않았다. 사용자가 별도로 Bake한다.**

## 적용한 변경

| 대상 | 이전 | 변경 |
|---|---|---|
| 투수 Cost 기본점 | 2.5 | 1.25 |
| 야수 Cost 기본점 | 2.5 | 2.5 유지 |
| 주력 | 도루 수, 기준점 55 | 도루 시도율 70%·성공률 30%, 기준점 67 |
| 타자 정신 | 타율, 기준점 55 | 출루율 70%·타율 30%, 기준점 63 |
| Cost 근거 | 능력치 Trace에서 간접 수집 | 가격 전용 `costMetricEvidence` |

평가 가중치는 원기록 자체가 아니라 기존 비교 집단·표본 신뢰도 보정을 거친 지표에 적용한다.
결측 지표는 분모에서 제외하며 전부 결측인 능력치는 조정 기준점 대신 55다.
Cost 품질·출전량·역할 보정·9/10 Cost 자격 조건은 유지했다. 가격 근거를 분리했으므로
주력에서 도루 수를 빼도 Cost의 도루 수 근거가 사라지지 않는다. 이 근거는 Runtime에서 제거된다.

Cost 후보는 기존 2011 관측의 Train 연도에서 -2~+2를 0.25 간격으로 비교하고
`MAE + 0.02 × |이동량|`을 최소화했다. 야수 -0.75 후보는 다른 연도·엑셀 비교에서 악화되어
채택하지 않았다. 투수 -1.25만 공통 적용했다. Source 야수 가격 변경은 0건, 투수는 6,004건이다.
능력치는 제한된 지표 조합과 중심 이동 0/4/8/12만 비교했다. 투수 구위·변화구 후보는
학습 3장·검증 1장으로 판단하기 어려워 채택하지 않았다.

## Cost 비교

아래 491건은 기존 코퍼스의 `OriginalObserved2011` 관측과 현행 Source를 연결한 집합이다.
Normal 판본이 확정되지 않은 관측이 포함되므로 **탐색 지표이며 최종판 정답 검증이 아니다.**
MAE는 평균 절대 오차이고 편향은 `계산 Cost - 참조 Cost`다.

| 집합 | 건수 | MAE 이전→이후 | 정확 일치율 이전→이후 | ±1 일치율 이전→이후 |
|---|---:|---:|---:|---:|
| 전체 | 491 | 1.200 → 0.996 | 29.12% → 32.59% | 66.40% → 74.13% |
| Train | 313 | 1.278 → 1.022 | 28.43% → 31.63% | 63.58% → 72.84% |
| Validation | 80 | 0.863 → 0.763 | 38.75% → 48.75% | 80.00% → 81.25% |
| Holdout | 98 | 1.224 → 1.102 | 23.47% → 22.45% | 64.29% → 72.45% |

전체 MAE는 약 17.0% 감소했고 평균 과대평가는 +0.935에서 +0.393으로 줄었다.
다만 Holdout의 정확 일치율은 하락했다. 이 분할은 기존 연구에서 이미 관찰됐으므로
완전히 새로운 비공개 검증 집합으로 해석하지 않는다.

엑셀의 Cost 233행 중 연도·팀·이름을 정확히 연결한 173행은 출처 시점별로 따로 비교했다.
나머지 60행은 이름만으로 강제 연결하지 않고 미연결 상태로 남겼다.

| 엑셀 출처 시점 | 연결 건수 | MAE 이전→이후 | 정확 일치율 이전→이후 | ±1 일치율 이전→이후 |
|---|---:|---:|---:|---:|
| 2010-04-06 | 7 | 1.000 → 1.000 | 14.29% → 14.29% | 85.71% → 85.71% |
| 2011 | 104 | 0.510 → 0.510 | 55.77% → 57.69% | 93.27% → 91.35% |
| 2013-11-15 | 62 | 1.161 → 1.032 | 25.81% → 24.19% | 64.52% → 74.19% |

엑셀은 기존 코퍼스와 일부 출처·선수가 겹친다. 491+173을 독립 표본 664건으로 합산하지 않는다.
2011 엑셀 MAE는 그대로이며 2013에서도 정확 일치율은 소폭 하락했다. 일반적인 투수 과대평가는
줄었지만 중하위 투수의 개별 가격까지 모두 개선된 것은 아니다. 예를 들어 1994 가내영은
참조 5에 기존 5→변경 3, 1995 이광우는 참조 4에 기존 2→변경 1로 오차가 증가했다.

Source Cost 분포도 바뀐다. 1 Cost는 3,092→4,452명, 9 Cost는 600→245명,
10 Cost는 326→307명이다. 이번 결과로 스카우트 경제·로스터 한도의 장기 균형까지 검증했다고
해석하면 안 된다. 전체 분포와 선수별 결과는 아래 CSV/JSON에 보존했다.

## 능력치 비교

카드 28장 중 정확히 연결한 26장 가운데 **Normal 12장(야수 8·투수 4)**만 아래 MAE에 포함했다.
EX/All Star/Unknown은 판본 보너스를 분리할 근거가 없어 제외했고 CSV에 제외 사유를 표시했다.
현재 Arm과 원작 Bunt는 다른 능력이다. 원작 번트를 송구의 정답으로 사용하지 않았다.

야수 2008~2009년 6장을 후보 선택에 사용했고 2010년 2장을 따로 비교했다.
주력은 학습 MAE 12.333→7.500, 별도 연도 8.000→4.000이고,
정신은 학습 8.500→5.167, 별도 연도 12.000→6.500이다.
특히 2010년 카드에는 기사와 이미지의 Cost 충돌도 있으므로 이 두 장을 확정적인 일반화
증거로 삼지 않는다. 이미지 값은 제공된 엑셀 전사값을 사용했으며 이번 구현에서 전 이미지의
훈련·재평가 시점까지 독립 확정한 것은 아니다.

**전체 6능력치가 원작에 근접했다고 결론 내릴 수 없다.** 수비·체력·제구·변화구의 잔여 오차가 크다.
체력의 427⅓이닝=100과 실측 170km/h=100은 현 프로젝트의 명시적 기준이어서 유지했다.
이 척도를 유지하며 원작 표시값까지 동시에 맞추는 데는 한계가 있다. 구속 결측 55도 실측값이 아니다.
다음 보정은 동일 시점 Normal 카드와 수비·구종 원기록 확보 후 진행하는 것이 타당하다.
엑셀의 수비 82행·구종 136행에 있는 `+N`은 상승 임계값이므로 기본 능력 학습에서 제외했다.

## 구현 검증과 범위

- Importer 전체 unittest **80/80**, 역사 데이터 관련 Headless EditMode **78/78** 통과.
  가격 근거 독립성·결측 중립값·설정 검증·Runtime 근거 제거를 새 회귀 테스트로 추가했다.
- 생성 Seed를 바꾼 두 Bake의 JSON **93개 전부 동일**. Runtime 데이터 JSON 46개를 복사 후
  바이트 비교했고, 검증 보고서는 Runtime 데이터 폴더 밖에 두었다.
- SimulationDiagnostics와 Headless 테스트 러너 빌드 통과. Headless에는 기존 직렬화 경고 3건이 있다.
- Unity 프로젝트의 Core/Simulation/Game/Game.Unity/Presentation 보조 컴파일 통과.
  Editor.Tests 보조 빌드는 기존 생성 csproj가 없는 `OwnerHomeVisualExporter.cs`를 참조해 실패했다.
  이 작업과 무관한 프로젝트 파일·다른 작업의 소스는 수정하지 않았다. Unity Test Runner/Play Mode 미실행.

밸런스 변경 영향은 DetailedMatchEngine에서 변경 전후 각각 10,000경기, 각 44건의 이벤트 결정론
비교로 측정했다. 전체 연도를 균등 표집하고 같은 Seed·대진 구성 절차를 사용한다. 각 Bake의
Core25를 쓰므로 능력치 변경에 따른 선수 구성 변화도 포함한다. 매 경기 피로 초기화,
우투우타·중립 전술·팀컬러 없음 조건이며 실제 커리어 전체 시즌 검증과 구분한다.

| 지표 | 이전 | 이후 |
|---|---:|---:|
| 타율 | .269 | .273 |
| ERA | 3.396 | 3.496 |
| 구단 경기당 득점 | 3.509 | 3.616 |
| 구단 경기당 홈런 | .616 | .624 |
| 볼넷/삼진 비율 | .480 | .504 |
| 구단 경기당 성공 도루 | .773 | 1.167 |
| 도루 성공률 | 69.38% | 69.73% |

도루는 약 51% 증가했다. 이는 주력 보정의 실제 경기 영향이며, 원작 경기 통계의 목표값을
확정하지 못했으므로 원작 재현 합격으로 판단하지 않는다. 경기 공식은 변경하지 않았다.
역사 캐시 Bake와 추가 장기 경제 검증은 이번 Cost·능력치 비교 결과에 포함하지 않는다.
