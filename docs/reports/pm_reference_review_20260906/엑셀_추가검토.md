입력: `docs/ref/프로야구매니저_연도_Cost_스탯_웹복원_자료.xlsx`.
SHA256: `C187654AE6803855F15994F9D87FE75A64E7B9ED24CBBE0CD724A67E677FB367`.
원본은 수정하지 않았다. 2026-09-06 기존 검토의 후속 자료이며, 아래 판단은 사용자 전사 데이터와 제한된 웹 원문 확인을 구분한다.

## 판단 변경

이 자료로 **초기 서비스 관측값에 대한 Cost·능력치 모델 비교를 시작할 근거가 늘었다.** 후기 Normal 정답만 기다리며 모든 실험을 미룰 필요는 없다. 초기 관측 시기별 진단과 후기 재현도 검증을 별도로 운영하는 편이 적절하다. 원작 전체 DB나 최종판 정답이 확보됐다는 의미는 아니다.

기존 491개 Cost 표본과 새 233건을 단순 합산하지 않는다. 기존 Corpus의 같은 연도·선수명 후보를 찾고 인벤 기사 ID와 Cost를 대조한 결과 70건이 같은 기사·같은 Cost 후보였다. 동일 기사에서 다른 Cost인 후보는 0건이었다. 144건은 기존 Corpus에 동일 연도·선수명 후보가 없었으며, 이는 Source 연결·버전 검수를 마친 신규 카드 144장을 뜻하지 않는다. 나머지 19건은 같은 선수 시즌 후보는 있으나 같은 기사·같은 Cost 조건을 충족하지 않는다. 팀 문맥과 날짜가 불완전하므로 자동 병합하지 않았다.

## 능력치 대응에서 반드시 지킬 점

[동시대 인벤 카드 설명](https://m.inven.co.kr/webzine/wznews.php?idx=86752&iskin=bm)을 직접 확인했다. 원작 야수의 네 번째 능력치는 번트다. 현재 프로젝트의 네 번째 능력치 Arm과 의미가 다르다.

| 원작 관측 | 프로젝트 비교 항목 |
|---|---|
| 교타·장타·주력 | Contact·Power·Speed |
| 번트 | 연구용 Bunt로 보존. Arm에 매핑하지 않음 |
| 수비·정신 | Defense·BatterMental |
| 투수 6항목 | Stamina·Velocity·Stuff·Breaking·Control·PitcherMental |

이름이 대응한다고 수치 스케일과 게임 효과까지 동일한 것은 아니다. 현재 Velocity는 구속 실측 앵커를 쓰므로 표시 숫자를 바로 동일화하면 안 된다. 원작 정신력 설명과 현재 AVG/ERA proxy 사이에도 개념 차이가 있다. 당장 Runtime 스탯을 바꾸기보다 비교용 이름 있는 필드와 단조 변환 후보를 먼저 사용한다.

[2010-10-20 구질 기사](https://www.inven.co.kr/webzine/news/?news=86866)는 추가 변화구 포인트에 따른 구종 등급 상승을 설명하고, 같은 시즌 선수의 특정 카드 종류 간 변화구 값 동일성을 명시한다. 이 설명을 모든 스탯·모든 시기의 Edition 동일성으로 확장하지 않는다. 구종별 +N만 있으면 시작 등급과 절대 경계를 모르므로 기본 Breaking을 유일하게 역산할 수 없다. 같은 판본의 기본 Breaking·현재 구종 등급·상승 경계가 같이 확보되면 제약식으로 활용할 수 있다.

엑셀의 이미지 전사 28장 중 연도·구단·이름·투타로 현재 Editor Source와 연결된 것은 26장이다. 2008 두산 김상현, 1994 LG 유지현은 미연결 상태로 남겼다. 개명 전후 이름일 가능성이 있어도 원본 인물 ID 근거 없이 자동 치환하지 않는다. 명시적 이름 이력 매핑을 추가하는 일은 연구용 Source 연결이며 선수별 가격 하드코딩과 다르다.

현재 비교 파일은 변형 카드의 보너스를 임의 차감하지 않고, 원작 관측값과 현재 baseAttributes를 나란히 보존한다. Normal 13장도 이미지 스냅샷 시점이 확정되지 않았으므로 후기 Normal CalibrationEligible로 승격하지 않았다. 모든 이미지 수치를 이번 턴에 재판독한 것은 아니다. 표본 이미지 URL은 웹 열기와 직접 다운로드 모두 실패해 `UserTranscription_ImageNotReverified`로 표시했다.

## 연구 자료 관리 방식

엑셀 행의 A/B/C는 원작성자가 부여한 `ClaimedEvidenceLevel` 성격으로 보존하고, 별도 필드로 이미지 재검수·날짜 정밀도·Source 연결·Normal 동등성·학습 정책 적격 여부를 둔다. A 등급 233건을 곧바로 233개의 확정 Normal 정답으로 세지 않는다. `일반/기사 문맥`도 명시적으로 종류를 판독한 Normal과 다르다.

관측 키는 다음 정보로 구성하는 것을 권장한다.

```text
ObservationId + SourcePlayerId/연결후보 + SeasonYear + SourceTeam
             + CardVariant + SnapshotId + SourceURL/ImageHash
```

이미지 주소의 `image_2011`은 스냅샷 날짜의 증명이 아니다. 출처 날짜와 카드가 실제 갱신된 날짜를 분리하며, 모르는 값은 Unknown으로 보존한다. 종류·시점이 다르면 동일 선수 시즌의 서로 다른 Cost를 덮어쓰지 않는다.
