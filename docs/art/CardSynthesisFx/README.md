# 선수 카드 합성 결과 FX

특수 영입 FX 확장 이후 재생 본체는 `UI_Popup_OwnerCardResult`로 공유한다.
기존 합성 진입점과 16프레임·12fps·결과 문구는 유지한다.

구단주 카드 합성이 `Enhanced`를 반환한 경우 갱신된 보유 카드 Snapshot으로 결과 팝업을 연다.
ImageGen 4×4 시트를 왼쪽 위부터 12fps로 1회 재생한다(약 1.33초).
카드 확대 펄스, 합성 성공 제목, 이전/현재 강화 단계를 표시한다.
하단 능력치·재료 소모 안내는 표시하지 않으며 빈 텍스트 영역도 생성하지 않는다.
합성 팝업은 호스트 대비 폭 30%·높이 74%로 줄이고 카드 크기는 기존과 동일하게 유지한다.
기존 `UIOwnerFrontOfficePanel`의 ManagerReport 스킨과 공용 Primary 버튼을 재사용한다.
특수 영입 팝업에도 동일한 축소 배치를 적용하고 하단 안내를 생략한다. 확인·취소 및 이전 포커스 복원은 유지한다.
확인·취소로 즉시 닫을 수 있으며 애니메이션은 `Time.unscaledDeltaTime`을 사용한다.
실패·재료 부족·최대 강화에서는 성공 연출을 표시하지 않는다. 게임 규칙·저장 동작은 변경하지 않았다.

## 자산

- `Synthesis-source.png`: ImageGen 원본 보존.
- `Synthesis-keyed.png`: 프로젝트 ChromaKey 도구로 초록 배경 제거한 중간 결과.
- `Assets/10.Datas/Resources/UI/CardSynthesisFx/SynthesisAtlas.png`: 1024×1024 RGBA, 256×256 16프레임.
- `Build-Atlas.ps1`: 프레임 경계 페이드·금빛 잔색 보정·정규 크기 변환.
- `Review-Atlas.ps1`, `AlphaReview.png`: 밝고 어두운 배경 합성 검수.

원본은 같은 중심의 금빛 입자 수렴 → 별빛 피크 → 원형 확산 → 소멸을 요청해 생성했다.
일반 인물용 검수 도구는 완전 불투명 픽셀이 없으면 실패하므로, 반투명 발광 FX는 별도 검수했다.
최종 알파 최대 253, 완전 투명 676,818 / 1,048,576 픽셀. 합성 화면에서 초록 잔색 제거를 확인했다.
프레임 경계는 14px에 걸쳐 감쇠해 인접 프레임 흔적과 잘림을 줄였다.

## 검증 범위

외부 Presentation 컴파일 오류·경고 0개. 이미지 합성 검수 완료.
사용자 지시로 에디터 테스트는 실행하지 않았다. 실제 Unity 결과 팝업의 해상도·입력·재생 검수는 남아 있다.
