# 선수 카드 컨디션과 스탯 표시

컨디션 화살표는 `Assets/Resources/UI/PlayerCards/PlayerCard_ConditionArrows_v1.png` 한 장에서 다섯 영역을 읽는다. 기존 컨디션 테이블의 표시 단계만 사용하며 수치나 경기 효과를 바꾸지 않는다.

| 컨디션 단계 | 표시 |
| --- | --- |
| 9–10 | 빨강 ↑ |
| 7–8 | 주황 ↗ |
| 5–6 | 노랑 → |
| 3–4 | 파랑 ↘ |
| 1–2 | 보라 ↓ |
| 미확인·비공개 | 숨김 |

보유 카드 목록·로스터 미니 카드에는 초상 왼쪽 아래, 메인 카드에는 기존 컨디션 패널 안에 수치와 함께 표시한다. 카드 디자인 창에서 색상별 미리보기와 타자·투수 전환을 제공한다.

타자는 **교타력·장타력·주력·번트·수비력·정신력**, 투수는 **체력·구속·구위·변화구·제구력·정신력**을 표시한다. 번트는 `BatterAttributes.CalculateBunt`의 기존 교타력 60%·정신력 40% 파생값을 사용한다. 송구력의 성장 출처를 번트에 재사용하지 않는다. 선수 커리어 대시보드의 여섯 항목도 같은 번트를 표시한다.

## 이미지 제작

내장 Imagegen 사용. 생성 원본은 `output/imagegen/card-condition/ConditionArrows-source.png`에 보존했다. 프로젝트 크로마키 제거 도구를 적용해 최종 RGBA PNG를 저장했다. 알파와 밝은·어두운 배경 합성, 실제 카드 크기를 확인한다.

최종 프롬프트: 5개의 동일한 칸으로 된 가로 UI 시트. 각 칸에는 은색 테두리의 유광 사각 버튼과 두꺼운 흰색 화살표. 왼쪽부터 빨강 위, 주황 우상향, 노랑 오른쪽, 파랑 우하향, 보라 아래. 작은 야구 카드에서 읽히는 정면 아이콘. 글자·숫자·추가 장식 없이 균일한 초록 #00FF00 배경, 배경 질감·그림자·전경 색 번짐 금지.

## 검증 자료

컴파일 및 Unity EditMode 결과: `output/CardCondition-EditMode.xml`.
실제 카드 캡처: `docs/reports/card-condition-validation/`.
화살표 열 단계 매핑·재바인딩 시 숨김, 타자·투수 항목과 값 연결을 검증한다. 본 프로젝트 Play Mode는 별도로 실행하지 않는다.
