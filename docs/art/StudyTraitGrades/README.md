# 유학·특성 SS/SSS

구단주 카드 육성의 유학과 특성을 C/B/A/S/SS/SSS 여섯 등급으로 확장했다.
선수 커리어의 별도 유학 시스템은 이번 대상이 아니다.

## 특성

| 등급 | 누적 경험치 | 효과 배율 | 다음 등급 훈련 비용 배율 |
|---|---:|---:|---:|
| C | 100 | 1.00 | 1.50 |
| B | 250 | 1.25 | 2.20 |
| A | 500 | 1.55 | 3.20 |
| S | 900 | 1.90 | 4.50 |
| SS | 1,500 | 2.25 | 6.00 |
| SSS | 2,400 | 2.60 | 최고 등급 |

최초 C 훈련 비용 배율은 1이다. `OwnerTraitTraining.json`이 경험치·효과·비용을 공급한다.
SS·SSS도 파트너는 최대 세 명이며 파트너 카드를 소모하지 않는다. 미리보기, 실제 비용 차감,
등급 도움말, 진행 막대, 최고 등급 차단, 저장 유효성 검사와 공용 배지를 함께 연결했다.
구단주 저장 버전 38. 배포 전 정책에 따라 마이그레이션은 추가하지 않았다.

## 유학

`CardStudyRank`는 해금 조건 종류와 독립된 정적 과정 속성이다. `OwnerDevelopment.json`의
등급별 과정 ID 목록으로 배정하며 기존 24개 과정과 지도 좌표를 유지한다.
각 등급에 야수·투수 과정이 모두 존재한다. 기존 과정의 일부가 상위 전문 과정으로 바뀐다.

| 등급 | 해금 | 기간 | 비용 PT | 기본 성장 합계 | 대성공 확률 | 추가 성장 |
|---|---|---:|---:|---:|---:|---:|
| C | 상시 | 1주 | 120,000 | 3 | 20% | 1 |
| B | 기존 리그 도달 조건 | 2주 | 350,000 | 7 | 15% | 2 |
| A | 포스트시즌 우승 | 3주 | 750,000 | 12 | 10% | 3 |
| S | World | 4주 | 1,300,000 | 15 | 10% | 3 |
| SS | Winners | 5주 | 2,100,000 | 18 | 8% | 4 |
| SSS | Galaxy | 6주 | 3,200,000 | 21 | 6% | 4 |

S 이상은 단계당 성장 +3에 비해 기간·비용을 더 요구하도록 설정했다. 기존 성장 상한과
시즌당 참가 제한을 사용하며 대성공은 주능력에 추가한다. 이 값은 장기 경제의 최종 확정값이 아니다.
지도에는 등급별 비행기 배지, 과정 정보에는 등급 문자, 카드에는 진행 과정 또는 활성 완료 효과의
최고 등급을 표시한다. 완료 원장의 과정명과 일치하지 않는 기록은 등급을 추정하지 않는다.

## ImageGen 자산

- `Grades_Source.png`: 특성 SS/SSS와 유학 C/S/SS/SSS 생성 원본.
- `Grades_Transparent.png`: 프로젝트 크로마키 제거 도구로 초록을 제거한 중간 시트.
- `StudyBA_Source.png`: 유학 B/A 생성 원본. 초록을 요청했으나 실제 RGBA로 반환돼 알파를 보존했다.
- `Export-Badges.ps1`: 시트를 분리하고 256px PNG·Unity Sprite 메타를 생성하는 재현 스크립트.
- `AlphaReview.png` 및 JSON: 8종의 밝고 어두운 배경 합성과 알파 측정.

특성 2종과 유학 6종 모두 모서리 알파 0, 등급 문자와 금속 프레임의 경계 보존을 눈으로 확인했다.
원본을 보존했으며 실제 자산은 `Assets/10.Datas/Resources/UI/PlayerGrowthBadges/`에 있다.

## 검증

- `Tools/StudyTraitGradeValidation`: 에디터·NUnit 없이 112건 통과. 여섯 등급의 야수/투수 과정,
  보상 총합·기간·비용·해금 경계, 특성 승급 경계, 실제 SS/SSS 훈련 명령·비용 차감·저장 복원·최고 등급 차단, 배지 파일을 검증했다.
- `SimulationDiagnostics trait-comparison 1000`: 무특성 1종과 14특성×C/S/SS/SSS, 57,000경기.
- `SimulationDiagnostics study-comparison 1000 development`: 무유학 야수/투수 대조와 24과정, 26,000경기.
- 모두 공통 상세 경기 엔진과 동일 시드 대조를 사용한다. 유학은 한 선수에게 대성공 최대 보상까지 적용했다.
- 외부 Presentation 컴파일 오류·경고 0개. SDK 접근 오류는 `TargetPlatformRootPath`와
  `SDKReferenceDirectoryRoot`에 `C:/Program Files (x86)/Windows Kits`, `TargetPlatformSdkPath`에
  `C:/Program Files (x86)/Windows Kits/10`을 지정해 해결했다.
- Headless Game 빌드에는 기존 저장 직렬화 API의 SYSLIB0050 경고 3개가 있다.

| 지표 | 특성 57조건 범위 | 유학 26조건 범위 |
|---|---:|---:|
| AVG | .290~.313 | .294~.302 |
| ERA | 4.579~5.424 | 4.773~5.016 |
| 팀당 경기 득점 | 4.713~5.537 | 4.867~5.130 |
| 팀당 경기 홈런 | .996~1.193 | 1.040~1.093 |
| BB/K | .389~.439 | .399~.417 |
| BB% | 7.05~7.47 | 7.26~7.43 |
| SO% | 16.17~19.22 | 17.59~18.58 |

교타 특성을 대상 팀 야수에게 적용한 승률은 무특성 51.2%, C 52.7%, S 55.6%, SS 56.4%,
SSS 56.8%였다. 지표는 양 팀 합산이며 팀당 득점·홈런으로 표기했다. 통제 능력치 50 로스터의
민감도 비교이므로 실역사 리그 평균이나 한 선수의 확정 승률 상승으로 해석하지 않는다.
원시 출력과 조건별 요약은 이 폴더의 `*-comparison.txt`, `*-comparison-summary.json`에 보존했다.

## UI 검수 범위

Skin/Layout Reference는 기존 `PlayerCardGrowthBadgesView`, 공용 툴팁, 유학 지도 핀,
`UI_Popup_OwnerTraitTraining` 도움말이다. 공용 셸·우측 배지 슬롯·호버·포커스·취소 경로를 재사용한다.
지도 입력 영역 44px와 배지 38px를 유지하고 도움말의 기존 등급 행을 여섯 칸으로 균등 배분했다.
새 Placeholder는 없다. 사용자 요청으로 에디터 테스트는 실행하지 않았다.
Unity 실화면, 해상도별 Bounds·입력·툴팁 배치는 미검수이며 UI 완료 조건을 모두 검증한 상태는 아니다.
