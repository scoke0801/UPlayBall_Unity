# 구단주 선수 카드 프레임과 COST 별

올스타·골든글러브의 최신 v3 원화와 골든글러브 줄기·잎 금색 예외는
[v3 제작 기록](OwnerPlayerCardFrames-v3.md)을 따른다. 아래 v2 프롬프트는 이전 제작 기록이다.

ImageGen 내장 도구로 제작했다. 최종 프레임은 사용자 지시에 따라 무채색이며, 모든 등급의 내부 영역 높이를 통일했다. SF형 장식과 유색 배경을 적용하지 않는다. 올스타 상단 리본은 제거했다.

- 프레임: `Assets/Resources/UI/PlayerCards/PlayerCard_{Mini|Full}_{Normal|AllStar|GoldenGlove|MVP}_v2.png` 8종, 모두 1060×1484.
- COST 별: 같은 폴더의 `PlayerCard_CostStar_{Normal|AllStar|GoldenGlove|MVP}_v2.png` 4종. 투명 PNG를 개별 Sprite로 배치한다.
- 프레임은 `PlayerCardEdition`으로 선택하며 이름·등급 라벨을 파싱하지 않는다.
- Mini 명찰은 아래 기준 18~28%를 모든 등급이 공유한다. 초상·이름·연도·COST·상태의 위치 및 크기에 등급 분기를 두지 않는다.
- Full 명찰 텍스트는 아래 기준 41.5~47.5%, 초상 창은 53.5~94%를 모든 등급이 공유한다.
- 실제 Cost를 숫자로 전달한다. 열 개의 별 슬롯 중 실제 비용만큼 밝게 표시하고 나머지는 어둡게 표시한다.
- 능력치·성장 기여·뒷면 성적·4×4 블록·구종 배치는 기존 Builder를 사용한다.
- 기존 커리어 카드에는 구단주 프레임을 강제로 적용하지 않는다.
