# 구단주 선수 카드 프레임과 COST 별

ImageGen 내장 도구로 제작했다. 사용자 피드백에 따라 SF형 금속 장식을 제외하고 원본 레퍼런스를 직접 입력해 다시 생성했다.

- 프레임: `Assets/Resources/UI/PlayerCards/PlayerCard_{Mini|Full}_{Normal|AllStar|GoldenGlove|MVP}_v2.png` 8종.
- COST 별: 같은 폴더의 `PlayerCard_CostStar_{Normal|AllStar|GoldenGlove|MVP}_v2.png` 4종. 투명 PNG, 개별 Sprite.
- 프레임 선택은 `PlayerCardEdition`으로 수행하며 이름·등급 라벨을 파싱하지 않는다.
- COST는 실제 숫자로 전달한다. 열 개의 별 슬롯 중 실제 비용만큼 밝게 표시하고 나머지는 어둡게 표시한다. 기존 비용 수치는 바꾸지 않는다.
- 능력치·성장 기여·뒷면 성적·4×4 블록·구종 배치는 기존 Builder를 사용한다.
- 미니 원화의 명찰 위치 차이는 `GetMiniNameBand`의 정규화 좌표로 맞춘다.
- 기존 공용 커리어 카드에는 등급 프레임을 강제로 적용하지 않는다.
