# 선수 카드 명찰·마크 수정 v5

사용자 후속 요청에 따라 이름을 문양 옆으로 피하는 v4 배치를 폐기한다.
이 문서가 v4 제작 기록의 이름·문장 겹침 수정 절보다 우선한다.

- 모든 이름은 카드 가로 중앙(x=50%)에 배치한다. 연도는 오른쪽 독립 영역이다.
- ImageGen으로 EX·MVP Full/Mini와 AllStar Full 총 5장을 다시 제작했다.
- EX·MVP Mini는 수평 명찰과 같은 이름 좌표(y=24%~30.5%, 아래 기준)를 사용한다.
  MVP 문장은 명찰 위에 축소 배치해 중앙 이름 영역을 비운다.
- Full AllStar·EX 마크는 구단명 아래로 옮긴다. 구단명 영역은 상단 2%~6%,
  초상 상단은 아래 기준 83%로 제한해 마크와 모자가 겹치지 않게 한다.
- 원화와 Unity 자산은 각각 `output/imagegen/player-card-frames-v5/`,
  `Assets/Resources/UI/PlayerCards/PlayerCard_{Full|Mini}_{Variant}_v5.png`에 보존한다.
  기존 자산은 보존하며 로더는 v5 → v4 → v3 → v2 순서로 선택한다.

## 생성 지시와 검수

ImageGen에 기존 등급별 v4 원화를 입력하고 단일 프레임씩 편집했다.
EX는 청색 방사형 배경·금색 날개, MVP는 자주색 광점 배경·야구공 문장,
AllStar는 청색 별 배경·은색 리본을 유지하도록 지정했다.
이름·연도·구단·선수·능력치·Cost는 이미지에 생성하지 않는다.
Mini 명찰은 위 기준 1000~1160px, Full은 760~905px를 목표로 요청하고,
첫 결과의 명찰 위치와 누락된 MVP 글자를 추가 편집으로 보정했다.
생성 원화의 정확한 경계에는 소폭 차이가 있지만 공통 텍스트 영역은 명찰 내부에 있다.

최종 5장 원화를 육안 확인했다. Presentation 및 테스트 어셈블리의 보조 컴파일을
수행한다. Unity 실제 합성 화면과 EditMode 실행은 열린 프로젝트의 별도 인스턴스
실행 제한으로 미검증이며, 원화 검수를 게임 화면 검증으로 간주하지 않는다.
