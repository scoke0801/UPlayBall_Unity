# 추가 선수 초상화 10개 시트 제작 기록

## 결과와 경로

내장 ImageGen으로 `sheet-002`~`sheet-011`을 추가 생성했다. 시트당 16명, 총 160명분이며
외형 ID는 `face-0017`~`face-0176`이다. 앞선 `sheet-001` 회색 배경 파일럿은 이번 후처리 대상에 포함하지 않았다.

작업 루트: `output/imagegen/player-portraits/production-576-v1/`.

| 산출물 | 경로 | 수량 |
| --- | --- | ---: |
| 생성 원본 | `sheets/raw/sheet-002__r01.png`~`sheet-011__r01.png` | 10 |
| 배경 제거 시트 | `sheets/transparent/sheet-002__r06.png`~`sheet-011__r06.png` | 10 |
| 최종 개별 투명 PNG | `faces/transparent/r06/face-0017__r06.png`~`face-0176__r06.png` | 160 |
| 실제 전송 프롬프트 | `prompts/sheet-002__r01.txt`~`sheet-011__r01.txt` | 10 |
| 밝고 어두운 배경 검토 | `previews/sheet-002__alpha-review-r06.png`~`sheet-011__alpha-review-r06.png` | 10 |
| 처리 좌표·파일 해시·알파 통계 | `manifests/sheet-002__background-r06.json`~`sheet-011__background-r06.json` | 10 |

마스터는 `sheet-576-v2`, 화풍 참조는 기존 `player-figurine-anchor-v1.png`다.
배경은 녹색 크로마키 `#00FF00`을 요청했다. 실제 생성 원본은 모두 1254×1254 RGB이며,
2048×2048 요청보다 작게 반환됐다. 업스케일하지 않았다.
셀의 실제 좌표를 기록하고 둘째 줄부터 상단 3픽셀을 보정해 앞줄 유니폼 하단의 혼입을 제거했다.

## 후처리와 검증

사용자의 후속 지시에 따라 생성 후 분할·배경 제거를 수행했다.
고도화 중인 원래 툴은 덮어쓰지 않고 `manifests/tool-snapshot-r06/`의 배치 전용 사본을 사용했다.
발견된 문제는 경계 거리 제한 누락으로 모자 내부가 반투명해지는 현상, 시트 분할선의 잔여,
목 주변 녹색 혼합 픽셀이었다. 사본에 경계 제한·녹색 복원 후보 제외·혼합 녹색 처리 보정을 적용했다.
이 사본은 녹색 키 전용이며 원래 툴의 일반화·통합 완료를 의미하지 않는다.

최종 배경 제거 검수:

- 개별 RGBA PNG 160개, ID 누락·중복 없음.
- 네 모서리 투명 검증 160/160 통과. 모든 파일에 완전 투명·완전 불투명 픽셀 존재.
- 원본 녹색 우세 픽셀과 캔버스 경계에서 떨어진 전경 검사 영역 7,328,764픽셀의 RGB/알파 변경 0건.
- `alpha > 16`, `G > R + 40`, `G > B + 40` 기준 녹색 잔여 0픽셀.
- 10개 시트의 160명 전부를 밝은 배경·남색 배경에 합성해 얼굴·모자·흰 유니폼 보존과 분할선 잔여를 확인했다.

배경 제거와 파일 납품은 완료다. 외형 고유성·실제 게임 카드 적용은 미검수이며 아트 상태는 `draft`다.
160개 ID가 서로 다르다는 것은 160개의 얼굴이 시각적으로 모두 고유하다는 증명이 아니다.
기존 시도 r01~r05는 이력으로 보존하며 **최종 선택은 r06**이다.

재개 시 얼굴 ID는 `face-0177`, 시트 ID는 `sheet-012`부터 사용한다.
생성 원본은 요청당 별도 프롬프트와 함께 보존하고 다음 배치에도 단색 크로마키 규약을 적용한다.
