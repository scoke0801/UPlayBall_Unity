# 선수 유니폼 10종

현재는 [구단 계보별 발급 기록](../../../Tools/PlayerUniforms/README.md)에 따라 10종을
역사 구단 계보에 연결했다. 5,760개 Unity 등록 및 시즌 18,326건 의상 발급, EditMode 4개가
통과했다. 아래의 구단 미배정·게임 연결 미완료는 이미지 제작 단계의 과거 기록이다.

576개 외형에 10종 유니폼을 적용하는 로컬 변환 도구를 제작했다.
최종 납품 루트는 `output/imagegen/player-portraits/uniforms-v3/`다.
v1·v2는 경계 보정 이전의 개발 샘플이며 v3를 사용한다.

## 중단 후 재확인 결과

2026-09-09 재개 시점에 시트 1~36과 576명 × 10종, 총 5,760개 PNG가 이미
디스크에 존재했다. 마지막 진행 메시지의 512명은 최종 디스크 상태와 달랐다.
이미지를 재생성하지 않고 `Test-Uniforms.ps1`과 `Review-Uniforms.ps1`을 다시 실행했다.

- 유니폼별 576개, 전체 5,760개 파일의 SHA256 일치, 조합 키 중복·누락 없음.
- 576개 투명 원본의 투명/불투명 픽셀 존재 및 네 모서리 투명 검사 통과.
  도구의 녹색 잔여 판정 기준에서 검출 픽셀 0개.
- 변환 당시 PNG 재독출 검사에서 얼굴 보호 영역·마스크 밖 RGBA 및 전체 알파 변경 0건.
  이번 재검증에서 해당 출력의 해시 일치를 확인했다.
- 눈·목 피부·알파 보존, 모자·상의 변환, 얼굴 침범 마스크 차단 회귀 테스트 통과.
- `previews/review-01.png`~`review-06.png`의 576명 축소 합성 및
  `previews/uniforms-10.png`의 얼굴 1·288·576번 × 10종을 직접 시각 확인했다.
  이는 5,760조합 모두의 원본 배율 수동 검수나 얼굴 고유성 승인과는 다르다.
- 카탈로그·알파 감사·검수판·갤러리를 갱신했다. 브라우저 조작은 재시도했으나
  도구 초기화의 `sandboxPolicy` 필드 누락 오류로 실행하지 못했다.

이 배치의 색상 변환과 파일 검증은 완료됐다. 실제 구단별 UniformId 연결과
Unity 카드 표시 검증은 이번 재개 작업에서 수행하지 않았으며 게임 적용 완료를 뜻하지 않는다.

## 사용

- 비교 갤러리: `index.html`. 선수 번호 1~576과 배경을 바꿔 10종을 비교한다.
- 대표 비교판: `previews/uniforms-10.png`.
- 인물별 파일: `portraits/{UniformId}/{AppearanceId}__{UniformId}.png`.
- 전체 조합 목록: `catalog.json`.
- 의상 마스크: `masks/{AppearanceId}.png`.
- 변환 전 투명 원본: `sources/transparent/{AppearanceId}.png`.

예를 들어 동일 인물 `face-0042`에 `uniform-02` 또는 `uniform-07`을 조회하면
얼굴이 같은 버건디·녹색 유니폼 이미지를 선택할 수 있다. 구단이 바뀌면 UniformId만 바꾼다.
576개 외형의 PersonId/LineageId 배정과 게임의 조회 연결은 후속 통합 범위다.

## 검증 기준

변환 시 저장 PNG를 다시 읽어 의상 마스크 밖 RGBA와 전체 알파 보존을 검사한다.
얼굴 중앙과 따뜻한 피부·머리 색상은 마스크와 별도로 검사하며 잘못된 마스크의 얼굴 침범을 차단한다.
흰 눈·목 피부·알파 보존, 모자·상의 색 변환, 얼굴 침범 마스크 차단 테스트를 수행한다.
전체 출력의 해시와 576×10 키를 검증하고 투명 원본의 녹색 잔여·모서리 알파를 별도로 검사한다.

실행법과 범위는 [도구 설명](../../../Tools/PlayerUniforms/README.md)을 따른다.
Unity 컴파일·EditMode·Play Mode는 이 독립 이미지 도구 작업에서 실행하지 않았다.
전체 얼굴 고유성·실제 카드 가독성·게임 리소스 메모리 검증도 별도다.
브라우저 연결 오류로 갤러리의 자동 조작 검증은 실행하지 못했다.
