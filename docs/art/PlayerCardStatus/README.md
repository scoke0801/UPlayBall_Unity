# 선수 상세 카드 상태 아이콘

## 강화 단계 원화와 상세 카드 배치 수정

- 강화·유학·특성·성장판·서포트를 공용 상세 카드 오른쪽 중심선(너비 91%)에 배치한다. 상단 94%에서 시작해 아이콘 크기의 1.3배 간격으로 내려가며 미보유 항목은 건너뛴다. 미니 카드 배치는 유지한다.
- 기존 PlayerCard 프레임과 PlayerGrowthBadges Sprite를 재사용하며 강화도 동일한 크기 계산을 공유한다. 최대 5개와 포커스 확대 1.08배를 고려해 카드 안쪽 여백을 유지한다.
- 사용자 요청에 따라 화살표와 런타임 숫자 덧씌우기를 제거했다. ImageGen 단일 `EnhancementLevels_Source.png`에 +1~+5를 직접 새겨 생성하고 은색→금색→월계·보석 장식으로 단계를 구분한다.
- `Build-EnhancementLevels.ps1`로 256px Sprite 5종을 분리한다. 실제 강화 상한은 `OwnedPlayerCardState.MaximumEnhancementLevel = 5`이며 단계별 Resources 자산에 직접 연결한다. 0강은 숨긴다.
- 생성기에 단색 크로마키를 요청했으나 반환 원본에 실제 알파가 있어 그대로 보존했다. `EnhancementLevels_FinalReview.png`에서 밝고 어두운 배경 합성, 숫자·장식과 투명 모서리를 육안 확인했다. 분리 경계를 조정해 +4에 이웃 +5 장식이 섞이지 않게 했다. 화살표가 있는 V2 초안은 docs에만 보존하며 게임에서는 사용하지 않는다.
- 외부 `dotnet build Baseball.Presentation.csproj --no-restore`는 별도 신규 `UI_Popup_OwnerCardSynthesis`가 생성 csproj에 포함되지 않아 참조 오류 1건으로 중단됐다. 에디터 테스트는 사용자 지시로 실행하지 않았다. 실제 게임의 해상도별 배치·포커스 검수는 미실행이다.

- 포지션을 등급별 이름 띠 왼쪽으로 이동했다. 이름·연도와 같은 명찰 대비색을 사용한다.
- 기존 포지션 위치에는 보유 카드의 잠금 상태를 열린/닫힌 자물쇠로 표시한다. 상세 팝업에서는 자물쇠 버튼으로 잠금/해제한다.
- 우측 상단 강화도는 ImageGen 금속 배지와 실제 강화 수치를 조합한다. 0강은 기존처럼 숨긴다.
- 상세 팝업과 전력보강의 공용 `BuildFrontCard`에 적용하며 미니 카드 배치는 변경하지 않았다.
- ImageGen으로 자물쇠 두 상태와 강화 배지를 한 장에 생성했다. `StatusIcons_Source.png` 원본을 보존하고 프로젝트 ChromaKey 도구로 초록 배경을 제거한 뒤 개별 Sprite로 분리했다.
- `AlphaReview.png`의 밝고 어두운 배경 합성을 육안 확인했다. 모든 Sprite 모서리는 투명하며 자물쇠 내부 틈도 제거됐다.
- 외부 Presentation 컴파일은 Game 레이어 매니저 뉴스 참조 오류 8건으로 중단됐다. 사용자 요청에 따라 에디터 테스트를 실행하지 않았다. 실제 게임 화면의 해상도별 배치 검수는 미실행이다.

## 카드 잠금 조작 추가

### 잠금 아이콘의 단색 사각형 표시 수정

- 자물쇠에 Button을 추가한 뒤 공용 `CareerUiSkin.ApplyButton`이 일반 버튼 스킨을 적용하며 Sprite를 제거하는 경로를 확인했다.
- 상태 아이콘 생성 시 `CareerUiVisualRole.DataImage`를 명시해 잠금·해제 아이콘과 강화 배지의 원화를 보존한다. 버튼 입력·상태 전환은 유지한다.
- 수정 후 외부 Presentation 컴파일 오류·경고 0개를 확인했다.
- 에디터 테스트와 실제 게임 화면 검수는 실행하지 않았다.

- 조사 당시 `IsLocked` 저장/복원과 합성·특수 영입 재료 보호는 있었으나 사용자 변경 Command와 버튼은 없었다. 일반 외 등급은 신규 획득 시 자동 잠금된다.
- 선수단·수집·전력보강 등에서 보유 선수 상세를 열고 좌측 상단 자물쇠를 누르면 잠금/해제를 즉시 저장한다. 상세 팝업 밖에 삽입한 카드 앞면은 상태 표시를 유지한다.
- `ManagerHistoricalRuntimeState.SetPlayerCardLocked`가 미보유 카드, 특수 영입 전용 카드의 영구 잠금, 예약 중인 재료 변경을 검증한다. 예약 변경은 저장 복원의 재료 검증과 충돌하므로 예약 취소 후 허용한다.
- `OwnerModeManager`는 기존 복사본 거래 경로에서 디스크 저장 성공 후 Runtime을 교체한다. UI는 최신 보유 상태를 읽으며 실패하면 기존 아이콘을 유지하고 오류를 표시한다.
- 잠금은 합성·특수 영입 재료 사용을 보호한다. 출전·성장 제한을 추가하지 않는다. 기존 저장 필드를 재사용하므로 저장 버전 변경은 없다.
- 후속 외부 Presentation 컴파일 오류·경고 0개. Game Headless 컴파일 오류 0개·기존 직렬화 경고 3개. 재료 보호·영구 잠금·저장 왕복 테스트 3건을 추가하고 테스트 어셈블리 컴파일 오류·경고 0개를 확인했다. 에디터 테스트와 추가한 테스트 실행, 실제 화면 조작 검수는 미실행이다.

## 미니 카드 포지션 중복 제거·강화 표시

- 공용 PlayerMiniCardView의 일반 미니 카드에서 좌측 상단 포지션을 숨기고 이름 띠 포지션은 유지한다. 편성 슬롯의 역할 헤더와 선수 선택 명찰은 유지한다.
- PlayerMiniCardModel에 실제 강화 단계를 전달하고 기존 PlayerCardStatus/Enhancement_1~5 Sprite와 DataImage 역할을 재사용한다. 수집·전력보강 공용 변환 및 선수단 카드에 연결한다. 0강과 카드 재바인딩 시 이전 배지를 숨긴다.
- 기존 미니 카드 프레임·정규화 레이아웃을 유지하고 우측 상단 96% 위치에 성장 배지와 같은 크기의 강화 아이콘을 배치한다. 입력·포커스 동작은 기존 카드가 담당하며 신규 Placeholder는 없다.
- 자산 5종 존재를 확인했다. SDK 경로를 명시한 외부 Presentation 컴파일 오류·경고 0개를 확인했다. 에디터 테스트·해상도별 실제 화면 검수는 사용자에게 맡긴다.
