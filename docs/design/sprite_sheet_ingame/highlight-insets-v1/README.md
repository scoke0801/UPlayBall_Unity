# 구단주 경기 하이라이트 삽입 이미지

타격·포구·홈런·슬라이딩·호수비·송구 6종을 제작하고 구단주 관전 화면의 우측 보조 영역에 연결했다. 경기장 스프라이트 모션과 별개인 불투명 장면 일러스트다. 각 `*-source.png`는 Imagegen 생성 원본이며 `*-prompt.txt`에 사용 프롬프트를 보존한다. Resources의 PNG는 원본과 동일하다.

| 파일 | 공개 사건과 표시 조건 |
| --- | --- |
| bat-contact | 인플레이 투구 공개가 끝난 접촉 순간 |
| glove-catch | 정상 뜬공 포구 또는 1루수의 직접 땅볼 처리 |
| home-run | 홈런 Hit 사건 공개 |
| slide | 도루 성공·실패, 2루타·3루타 타석 종료 |
| great-catch | 실패하지 않은 비일상적 라인드라이브 포구 |
| power-throw | 1루수 직접 처리 외 정상 땅볼 아웃·희생번트 처리 |

송구 첫 두 후보는 손가락 중첩과 동작의 불명확함 때문에 제외했다. 최종 원본은 인물을 오른쪽에 두고 송구 손과 글러브를 분리한 새 구도다. 선수 개별 외형이나 특정 구단을 재현하는 이미지는 아니다.

## 연결 계약

`OwnerMatchHighlightCue`는 이미 공개된 단일 사건만 소비한다. 이후 결과를 미리 보여주거나 결과를 재계산하지 않는다. 슬라이딩 이미지 자체에는 세이프·아웃 판정을 넣지 않는다. 상세 투구 정보와 이미지는 같은 영역에 교대로 표시하며 점수판·현재 투타·감독 판단 영역은 유지한다.

기존 Owner 화면의 색상·글꼴·보조 패널을 재사용한다. 새 버튼이나 포커스 대상은 없다. 표시 시간과 이미지·문구는 `Assets/10.Datas/Resources/UI/OwnerMatch/Highlights/HighlightPresentation.json`에서 조정한다. 기본 0.9초, 배속에 따른 최소 0.5초이며 등장·퇴장 페이드를 적용한다. 일시정지 시 표시 시간도 멈추고, 종료·즉시 결과·화면 숨김·모드 변경 시 잔류 이미지를 해제한다.

## 검증

- 격리 Unity EditMode 기본 검증 필터: **74/74 통과**, 실패 0. 이미지 리소스·사건 선택·수비 실패 제외·배속별 노출·상세 정보 복귀·화면 숨김을 포함한다.
- 원본/런타임 SHA256 일치, 1672×941 비율, 불투명 알파 검사: **6/6 통과**. `Tools/SpriteMatchValidation/verify_highlight_assets.py`로 재검사한다.
- 실제 상세 경기 Seed 20260911의 954개 사건을 관전 3모드 × 1·2·4배속으로 끝까지 재생했다. 모든 조합의 최종 점수는 공식 BoxScore와 같은 10:11이다. 결과 전용 모드는 이미지를 표시하지 않는다.
- 실제 재생에서 6종 모두 자연 발생했다. 첫 공개 사건 번호는 타격 4, 송구 8, 슬라이딩 40, 포구 52, 홈런 76, 호수비 160이다. 활성 이미지와 마지막 공개 사건의 일치를 검사한다.
- 일시정지 중 사건·이미지 시간 정지, 즉시 결과 버튼 콜백을 통한 취소, 경기 종료 후 이미지 해제와 결과 표시를 검사했다.
- 1280×720, 1920×1080, 2560×1440, 3440×1440 × 6종의 **24개 정적 합성**에서 우측 영역 경계·기존 정보 숨김·입력 비차단을 검사했다. 대표 화면을 육안 확인했다. 정적 합성은 사건 연결 검증과 구분한다.

실행 산출물은 `output/sprite-sheet-validation/`에 있다. `editmode-results.xml`, `highlight-image-qa.json`, `owner-session-replay.csv`, `highlight-inset-replay.csv`가 근거이며, `inset-replay-*.png`는 실제 경기 사건으로 표시한 화면, `inset-<종류>-<해상도>.png`는 배치 검사용 고정 합성이다.

이 검증은 격리 Unity EditMode에서 실제 관전 세션과 화면 갱신 함수를 호출한다. 메인 프로젝트 새 게임부터 진행하는 Play Mode, 실제 마우스·키보드·게임패드 입력 및 공용 셸 통합 검증은 수행하지 않았다. 시뮬레이션·밸런스 수치는 변경하지 않았다.
